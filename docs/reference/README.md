# 开发参考资料边界

本目录中的 PDF 和 XLSX 只供开发期提取、核对与本地验收使用。它们不是第一版 Skill 的运行时依赖，也不得直接进入公开发布物。

## 第一版规则基线

第一版只以以下确定版本作为三宝书规则基线：

- `5e/5e译稿/5eDnD_玩家手册PHB_中译v1.72版.pdf`
- `5e/5e译稿/5eDnD_城主指南_中译v1.1.pdf`
- `5e/5e译稿/5eDnD_怪物图鉴MM_中译 v1.3.2（配图）.pdf`

`5e/5e译稿/5eDnD_怪物图鉴MM_中译 v1.3（纯文字）.pdf` 与 `5e/5e译稿/DnD5e_词表_中译v1.0.xlsx` 仅是辅助参考，不能覆盖或补写三宝书规则基线。

## 转换与运行时交付

[GitHub Issue #4](https://github.com/Hanray-Zhong/dnd-skill/issues/4) 负责在开发期批量处理上述三本固定副本，生成完整的语义规则章节、规则实体 Markdown、索引、来源元数据和内容哈希。单份样本只能用于测试构建器，不能代替三宝书完整交付。

运行中的 Skill 只能检索已经生成并固定版本的资产，不得读取、解析或要求存在本目录中的 PDF/XLSX，也不得调用开发构建工具链。删除或隔离本目录后仍能完成规则查询，是 Issue #4 的运行时边界验收条件。

生成内容可以进入本地预览包；只有来源授权清单完整且通过发布门禁后才能公开分发。无论授权状态如何，原始 PDF、XLSX、提取缓存和临时中间文件都不得进入 Skill 包。

## 标准模组样本

`5e/模组/5eDnD_梵杜尔的失落矿坑_中译.pdf` 只用于定义模组导入契约和本地验收，不属于内置可玩内容，也不随 Skill 发布。

## 其他保留资料

目录中的其他参考文件属于已保留的重要开发资料，但不在 Issue #1 的第一版规则或模组范围内。除非未来通过 Issue、领域术语和 ADR 显式扩大范围，否则不得将其用于权威裁定、构建输入或运行时检索。

任何准备随包分发的生成文本或视觉资产都必须先满足来源授权清单与文件哈希要求；拥有本地参考文件不等于拥有公开转换或分发授权。
