# DM 投骰使用本地骰子引擎

当规则提供骰式时，怪物、NPC、环境、伤害、先攻、充能、随机数量和随机表默认由主持 Agent 调用本地骰子引擎，而不采用资料板平均伤害，也不让模型自行产生数字；玩家角色默认由玩家报告骰子，但可逐人授权脚本代掷，私密预掷池只作为可选策略。骰子引擎只解析有限的加法骰式，并以结构化选项支持保留、丢弃和指定面值重掷；生产环境使用系统安全随机源且不接受外部种子，测试可以注入可重复随机源，解析器禁止 `eval` 并限制输入规模。输出记录每颗原始、丢弃和重掷面值以及最终总值。该选择提高暗骰与战斗节奏并保持可审计性，代价是发布 Skill 必须包含经过边界、规则和随机性测试的安全骰式解析器。
