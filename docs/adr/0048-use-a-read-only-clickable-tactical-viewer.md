# 使用只读的可点击战术查看器

第一版可以提供由原生 HTML、SVG 和少量本地 JavaScript 构成的专用战术查看器；地图修订时只生成已经完成知识投影的渲染输入，玩家点击棋子后再按当前移动预算计算最短路径树，并以 `projectionRevision + entityId + movementMode + movementPolicy` 缓存，当前行动者可以空闲预热但不得默认预计算或发布所有玩家的全图树。点击棋子只高亮当前可达格，点击格子只预览路径、消耗和可感知风险；查看器、缓存与性能诊断均不得接收隐藏权威输入，也不得写入战役状态、拖拽棋子或编辑地图，最终移动仍通过对话确认并进入可中断结算链。不支持交互 HTML 的环境退回静态 SVG 与自然语言或坐标查询；原型在 50×50 方格、四名可控玩家夹具上验证了按点击计算的低延迟与较小发布体积，证据保存在 `docs/prototypes/tactical-viewer/HANDOFF.md`。该选择提供接近实体棋盘的快速查询而不扩展为完整 VTT，代价是发布物需要维护严格只读、按修订失效缓存且具备静态回退的专用视图组件。
