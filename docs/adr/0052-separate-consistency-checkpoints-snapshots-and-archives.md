# 分离一致性检查、恢复快照与可移植归档

每次会话结束只在角色状态对账后提交 session_closed 事件并执行 SQLite 一致性检查与 WAL checkpoint，不默认复制完整数据库；完整快照只在兼容组合迁移前、修复前或管理者明确请求恢复点时通过 SQLite 一致性备份接口生成，并记录战役、修订、原因、兼容组合与哈希且不自动删除。可移植归档只由管理者显式生成，包含根清单、战役输入档案和一致性状态库快照，可选包含人类可读投影，但排除运行目录、缓存、旧归档和共享规则资产，恢复只能进入新建或空目录并先验证完整性与兼容性。该选择避免长期战役按会话重复整库膨胀，同时保留迁移回滚、人工恢复和工作区迁移能力。
