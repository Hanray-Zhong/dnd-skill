# 通过角色状态对账协调玩家记录与战役状态库

线上或线下玩家可以独立维护自己的角色记录，主持 Agent 同时在战役状态库中维护权威战役记录，并通过 OOC 对话呈现带修订的角色状态表进行对账；开团与收团在共享桌面一次展示全体完整角色状态表，关键检查点展示变化分区，普通事务只发送状态回执，内部数据库和文件格式不向玩家暴露也不要求交换文件。完整角色状态表默认向全队公开，但该公开不扩展到角色内心、尚未分享的角色认知、安全信息或 DM 隐藏状态。玩家记录只构成受字段变更权限约束的状态声明，任何一方都不能在冲突时自动覆盖另一方；依赖冲突字段的结算必须暂停，从最后一个双方确认的修订与事件记录复原，经 OOC 协商后以更正事件和新状态事务提交共同确认结果。本次参与角色必须确认状态后才能产生机械后果，未确认角色按既有缺席策略处理且不阻塞其他玩家开团。该选择保留纸面或线上玩家的自主记账习惯并允许纠正 Agent 错误，代价是需要维护确认修订、差异报告和未解决冲突状态。
