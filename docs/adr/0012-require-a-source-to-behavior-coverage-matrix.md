# 以来源到行为覆盖矩阵作为发布门槛

第一版维护来源到行为覆盖矩阵，先以三宝书章节、标准模组结构和跨领域场景建立设计基线，再由开发构建工具链扩展到语义规则章节与规则实体条目。规则与模组行为行必须引用 ADR-0032 中的稳定 Skill 标识并指定一个主责 Skill；构建、计算和投骰等系统行可以指定明确命名的支持组件，但不得把它注册为额外 Skill。所有行记录激活条件、协作方、权威状态、可观察结果、异常路径、验收场景和验证状态；未分配主责、职责重叠未解释、默认或条件规则未映射以及必需行未验证时均禁止发布。通用实体契约可以覆盖同构法术、怪物和物品，但必须包含代表性特殊案例。该选择使“完整覆盖”成为可检查声明，代价是来源、职责和测试变化都必须同步维护矩阵。
