# Triage 标签

Matt Pocock 的 skills 使用五个 canonical triage roles。本文件将这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| Matt Pocock skill 中的标签 | 本仓库 tracker 中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估此 Issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某个 role（例如“添加 AFK-ready triage label”）时，使用表格右侧对应的标签字符串。

如果本仓库实际使用其他标签词汇，编辑右侧列以保持映射一致。
