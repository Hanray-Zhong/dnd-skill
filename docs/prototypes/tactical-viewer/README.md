# D&D 5E 可点击战术查看器（抛弃式原型）

> **THROWAWAY / 禁止进入生产。** 本目录只用于回答交互与性能问题，不是正式实现，也不写入战役状态。

本原型已作为持久设计参考保存在仓库中。正式实现必须以规格、ADR 和覆盖矩阵为准；原型代码、测试夹具与生成产物只用于复现实验和验证设计取舍。

设计问题：使用本地 HTML + SVG + 少量 JavaScript，能否让玩家点击自己的棋子后快速显示当前可达格，再点击目标格预览最低移动消耗路径，同时保持只读、不泄露隐藏信息，并提供静态 SVG 回退？

本原型采用 UI 分支 B（新页面），因为仓库仍处于设计阶段，没有可承载原型的现有页面。单一路由提供三种结构差异明显的布局，通过 `?variant=A|B|C` 或底部浮动切换器选择：

- A：地图优先 + 右侧检查器，适合桌面战斗操作。
- B：路线工作台 + 底部时间线，突出移动预算与风险。
- C：安静棋桌 + 浮动摘要，检验最少覆盖层是否够用。

## 一条命令运行

```bash
./run.sh
```

默认打开地址：`http://127.0.0.1:8787/?variant=A&map=small`。可用 `TACTICAL_PROTOTYPE_PORT` 覆盖端口。服务器只发布 `public/`，包含隐藏敌人、陷阱和秘密通道的权威测试夹具不在可访问目录内。

## 人工检查路径

1. 点击玩家棋子“艾拉”。
2. 在“普通移动 / 疾走”之间切换，观察基础范围和疾走新增范围。
3. 在疾走模式点击 `L7`，查看最低消耗路径、距离、消耗、剩余移动力和明显借机攻击风险。
4. 切换 `50×50` 地图感受大图操作。
5. 禁用 JavaScript 或直接打开 `public/artifacts/static-fallback.svg` 检查静态回退。
6. 展开左下角“性能诊断（原型专用）”，可在当前浏览器运行 20 轮真实 DOM 基准。

## 目录边界

- `fixtures/`：仅用于验证投影隔离的 DM 权威夹具；不会由服务器发布。
- `tools/`：投影、验证、基准、截图与静态 SVG 生成脚本。
- `public/`：可发布给玩家的纯本地只读查看包。
- `HANDOFF.md`：把实验结论带回设计对话的交接文档。

原型不包含保存、拖拽、移动提交、网络写请求或战役状态接口。重新加载页面会清空全部预览状态。
