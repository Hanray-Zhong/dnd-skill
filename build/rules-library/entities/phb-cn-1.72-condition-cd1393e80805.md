# 魅惑 Charmed

• 被魅惑生物不能攻击魅惑者，其造成伤害的能力或魔法效应  
也不能以魅惑者为目标。  
• 魅惑者对被魅惑生物进行任何与社交相关的属性检定时具有  
优势。
