# 盾牌 Shield， +1、 +2 或 +3

护甲（盾牌），非普通（+1），珍稀（+2），极珍稀（+3）  
持握此盾牌时，你将依据盾牌本身的 AC 加值基础上获得  
额外的加值。加值的数值取决于该盾牌的稀有度。
