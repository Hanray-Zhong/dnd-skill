# 震慑 Stunned

• 被震慑生物陷入失能状态（见“失能”），并且  
无法移动，以及无法清晰连贯地说话。  
• 被震慑生物进行力量和敏捷豁免时直  
接失败。  
• 对被震慑生物发动攻击检定时具有优势。
