# 交流方式 Communication

智能魔法物品有一定的交流能力，它们会表达自己的情  
绪，心灵感应传递思想，或是直接大声的说出来。你可以按照  
下表决定物品的交流方式  
| d100 | 交流方式 |
| --- | --- |
| 01~60 | 物品向持有者或持握者传递情绪进行交流。 |
| 61~90 | 物品能够听、说、读一门或多门语言。 |
| 91~100 | 物品能够听、说、读一门或多门语言，并且还能与 |
|  | 持有者通过心灵感应进行交流。 |
