# 唤鱼三叉戟 Trident of Fish Command

武器（三叉戟），非普通（需同调）  
该三叉戟是一把魔法武器。它有 3 发充能。持握它时，  
你可以用一个动作并消耗 1 发充能以对一只有天生游泳速度  
的野兽施展支配野兽 dominate beast （DC 15）。该三叉戟每天  
黎明时恢复 1d3 发已消耗的充能。
