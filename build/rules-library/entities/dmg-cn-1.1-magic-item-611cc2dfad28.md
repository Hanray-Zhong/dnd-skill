# 屠龙者 Dragon Slayer

武器（任意剑），珍稀  
你用该魔法武器发动的攻击检定和伤害掷骰获得 +1 加值。  
你以该武器命中龙类时，它将受到与剑的伤害类型相同  
的额外 3d6 伤害。此处的“龙”指任何生物类型为龙类的生  
物，包括龙龟 dragon turtle 和飞龙 wyvern 等。
