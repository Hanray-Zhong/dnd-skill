# 束缚 Restrained

• 被束缚生物的速度变为 0，并且无法受益于任何速度加值。  
• 对被束缚生物发动攻击检定时具有优势，被束缚生物发动攻  
击检定时具有劣势。  
• 被束缚生物进行的敏捷豁免具有劣势。
