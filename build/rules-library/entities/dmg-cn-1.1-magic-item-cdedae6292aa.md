# 异界之门魔方 Cubic Gate

奇物，传说  
这个棱长 3 寸的立方体散发着明显的魔法能量。立方体  
的六个面分别对应六个位面，其中之一是物质位面其他则由  
DM 决定。  
你可以用一个动作按下立方体的某个面以施展法术异  
界之门 gate，并打开连接对应位面的传送门。或者，你可以  
用一个动作按两次立方体的某个面来施展法术异界传送  
plane shift （豁免 DC 17），以将你的目标传送到对应位面。  
立方体有 3 发充能，每次使用都会消耗 1 发充能。它可  
以在每天黎明时恢复 1d3 发充能。
