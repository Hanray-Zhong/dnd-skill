# 擒抱 Grappled

• 被擒抱生物的速度变为 0，且无法受益于任何速度加值。  
• 如果擒抱者陷入失能状态（见“失能”），则擒抱状态结束。  
• 如果某种效应将被擒抱生物移动到擒抱者或擒抱效果的接触  
范围之外，则其擒抱状态结束。例如，当生物被法术雷鸣波  
thunder-wave 推开时。
