# 蛛网魔杖 Wand of Web

魔杖，非普通（需施法者同调）  
这把魔杖有 7 发充能，且每天黎明时恢复 1d6+1 发已消  
耗的充能。当充能耗尽时，骰一次 d20。如果骰值为 1，魔杖  
将化为灰烬而毁灭。  
持握此魔杖时，你可以用一个动作并消耗 1 发充能以施  
展蛛网术 web （豁免 DC 15）。
