# 火巨灵链甲 Efreeti Chain

护甲（链甲），传说（需同调）  
着装该护甲时，你的 AC 获得 +3 加值，且免疫火焰伤害，  
还可以说和理解原初语 Primordial。此外，你还可以像在坚实  
地面上一样行走于熔岩上。
