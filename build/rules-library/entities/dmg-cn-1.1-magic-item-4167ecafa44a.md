# 阵营 Alignment

智能魔法物品有阵营。它的创造者或其本性会使其倾向  
某个阵营。如果没有被赋予，则你可以赋予它一个阵营，或者  
按照下表决定其阵营。  
| d100 | 阵营 | d100 | 阵营 |
| --- | --- | --- | --- |
| 01~15 | 守序善良 | 74~85 | 混乱中立 |
| 16~35 | 中立善良 | 86~89 | 守序邪恶 |
| 36~50 | 混乱善良 | 90~96 | 中立邪恶 |
| 51~63 | 守序中立 | 97~00 | 混乱邪恶 |
| 64~73 | 绝对中立 |  |  |
