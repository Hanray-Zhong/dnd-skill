# 移除诅咒 Remove Curse

3 环防护  
施法时间：１动作  
施法距离：触及  
法术成分： V、 S  
持续时间：立即  
你的触碰立即为一个生物或一个物件解除其身上的所有诅  
咒。如果目标物体是一件被诅咒的魔法物品则其上的诅咒不会  
因此解除，不过该法术可以打破诅咒物品与其所有者之间的同  
调，使其所有者可以将其卸下或丢弃。
