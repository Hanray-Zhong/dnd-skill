# 幻惑镶钉皮甲 Glamoured Studded Leather

护甲（镶钉皮甲），珍稀  
着装该护甲时，你的 AC 获得 +1 加值。你可以用一个附  
赠动作说出该护甲的命令语，使护甲的外观幻化为任何普通  
衣物或其他种类护甲。护甲的颜色，样式和配件都由你自己决  
定，但它的体积和重量不会改变。幻化外观的效应持续到你脱  
掉此护甲或再次改变护甲外观。
