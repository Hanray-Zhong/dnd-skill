# 元素宝石 Elemental Gem

奇物，非普通  
这种宝石蕴藏着操纵元素的能量。你可以用一个动作来  
打碎宝石，其效应如同你施展法术召唤元素生物 conjure  
elemental 一样召唤出一个元素。被打碎的宝石也将失去魔力。  
宝石的种类决定了法术所召唤的元素。  
| 宝石 | 召唤的元素 |
| --- | --- |
| 蓝色蓝宝石 blue sapphire | 气元素 |
| 黄钻石 yellow diamond | 土元素 |
| 红刚玉 red corundum | 火元素 |
| 翡翠 emerald | 水元素 |
