# 防御者 Defender

武器（任意剑），传说（需同调）  
使用此魔法武器发动的攻击检定和伤害掷骰获得 +3 加值。  
你在每个自己回合里第一次使用此剑攻击时，可以选择  
将此剑的加值全部或部分转移到你的护甲等级中，而非用于  
本回合的任何攻击。例如，你可以将攻击检定和伤害掷骰的加  
值降低到 +1 而在 AC 上获得 +2 加值。加值改变持续到你的下  
一回合开始。你必须握持此剑才能获得它提供的 AC 加值。
