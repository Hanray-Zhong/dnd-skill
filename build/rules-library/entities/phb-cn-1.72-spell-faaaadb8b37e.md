# 维生术 Spare the Dying

死灵戏法  
施法时间： 1 动作  
施法距离：触及  
法术成分： V、 S  
持续时间：立即  
你触碰一个生命值为 0 的活体生物，使该生物的伤势立刻  
稳定下来。该法术对不死生物和构装生物无效。
