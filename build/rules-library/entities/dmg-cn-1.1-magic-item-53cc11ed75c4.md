# 万溶剂 Universal Solvent

奇物，传说  
这管乳白色的液体散发着浓烈的酒精气味。你可以用一  
个动作将管中液体倒在触及范围内的某表面上。万溶剂将立  
刻溶解它接触到的至多 1 立方尺的粘合剂（包括至尊胶  
sovereign glue）。
