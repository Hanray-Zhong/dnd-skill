# 武器 Weapon， +1、 +2 或 +3

武器（任意），非普通（+1），珍稀（+2），极珍稀（+3）  
你在用此魔法武器发动的攻击检定和伤害掷骰获得加值。  
加值的数值取决于武器的稀有度。
