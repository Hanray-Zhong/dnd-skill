# 特性：公会成员 Feature: Guild Membership

你身为公会中一名备受尊敬的正式成员，可以享受到公会  
所提供的一些好处。公会中的同僚会在你需要时为你提供食宿，  
甚至在必要时为你安排身后事。公会在某些市镇设置有会馆，  
你可以以此作为与同行交流的场所，也可以从中开发潜在的客  
户、合作伙伴或雇工。  
公会常常掌握着庞大的政治资源。当你被指控某项罪名时，  
公会可以为你提供全面的支持，前提是你必须为自己的清白做  
出举证，或是你的罪名必须仍可接受辩护。倘若你身处公会高  
层，甚至可以藉由公会获取有力的政治地位。而这些人脉资源  
都需要你为公会捐赠金钱或魔法物品来维持。  
你每个月必须上交 5 gp 作为会费。若你因故未缴这笔费  
用，则必须在补齐后才能重获公会的青睐。
