# 明亮的地洞 Bright Burrows

侏儒们的家园建立在崎岖丘陵或林木繁盛的地带。他们的  
地下居所与矮人不同，这里有着更清新的空气且随时可以享受  
地表生活的乐趣。侏儒的家以巧妙的建造和简单的幻术高明的  
隐藏起来。受欢迎的访客会被迅速引导入明亮温暖的洞室里。  
而那些不受欢迎者则很难在同样的地方找到前往洞室的方向。  
居住在人类领地中的侏儒通常是宝石切割师、工程师、智者  
或是修补匠。一些人类家庭会雇用侏儒来担任家庭教师，以使  
其子女们能像侏儒们一样在认真学习的同时享受快乐。而一名  
侏儒在其漫长的寿命里，可能会为同一个家族里的好几代人进  
行授课。
