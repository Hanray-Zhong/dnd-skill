# 步骤 2. 体型 Size

为你的怪物设定你理想的中的体型：微型、小型、中型、  
大型、巨型、超巨型。  
怪物的体型同时也决定了步骤 8 里用来计算其生命值的  
骰子面数。怪物的体型也决定其占据的空间位置大小，如同  
《玩家手册》中所述。
