# 即时死亡 Instant Death

巨大的伤害可以立刻干掉你。当有伤害把你的生命值降为  
0，且溢出的伤害值等于或大于你的生命值上限时，你即时死亡。  
例如，一名牧师其生命值上限为 12，而现有生命值为 6。  
如果她受到 18 点伤害，则其生命值降为 0 后依然溢出 12 点伤  
害。由于这些溢出的伤害等于其生命值上限，因此该牧师即时  
死亡。
