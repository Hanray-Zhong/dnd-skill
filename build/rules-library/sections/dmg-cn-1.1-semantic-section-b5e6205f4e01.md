# 选用规则：残酷累赘 Cruel Hindrance

该位面的残酷本质使这里的旅行者难以实现互相帮助。  
旅者被施予增益效应的法术（包括恢复生命值或移除某状态）  
时，其施法者必须先进行一次 DC10 的魅力豁免。豁免失败则  
施法失败，相应的法术位被消耗，相应动作也被花费掉。
