# 城中遭遇

尽管城市总会承诺保障安全，但城镇中依然存在如黑暗  
地牢一样的危险。邪恶潜藏在众目睽睽之下或躲在黑暗角落  
里。下水道、阴暗小巷、贫民窟、烟雾弥漫的酒馆、破旧的公  
寓、拥挤的市集都可以瞬间变为战场。最重要的是，冒险者们  
必须学会举止得体，以免招来当地政府不必要的关照。  
换言之，角色们只要不自找麻烦，就可以享受聚居地为其  
带来的所有好处。
