# 激活物品 Activating an Item

一些魔法物品需要其使用者做一些特别的事情才能激活，  
比如拿着物品说出相应的命令语。每个物品品类或单个物品  
的描述中都详述了激活该物品的方法。而某些特定的物品会  
使用下列其一或多项作为其激活规则。  
如果某物品需要用一个动作激活，则该动作本身并不作  
为“使用物品 Use an Item ”动作，因此一些特性，如游荡者  
的“快手 Fast Hands ”特性就无法用于激活这些物品。
