# 生命值 Hit Point

生命值代表了肉体与精神耐受性、生存意志强弱以及运气  
好坏等因素的综合评估。具有高生命值的生物更难被杀死。而  
具有低生命值的生物则更加脆弱。  
生物的当前生命值（通常直接叫生命值），可以是 0 到生命  
值上限之间的任何数值。随着一个生物受伤和接受治疗，其生  
命值也会出现频繁的波动。  
当生物受到伤害时，对应伤害值将从其生命值中扣除。在  
生命值降为 0 前，该数值减少不会影响生物的正常活动力。
