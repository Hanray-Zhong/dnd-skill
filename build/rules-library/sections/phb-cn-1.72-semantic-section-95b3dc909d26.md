# 击晕 Knocking a Creature Out

有时攻击者会想活捉敌人，而不是直接杀死。当一名攻击  
者用近战攻击将某生物的生命值降为 0 时，攻击者可以选择将  
其击晕。攻击者可以在造成伤害的一瞬间作出决定。被击晕的  
目标陷入昏迷，但伤势稳定。
