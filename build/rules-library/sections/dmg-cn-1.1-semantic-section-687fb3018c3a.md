# 创作魔法物品

第 7 章“宝藏”中的魔法物品不过是一些角色们在冒险  
中发现的魔法宝藏。如果你的玩家是经验丰富的老手而你想  
给他们制造点意外惊喜的话，这时你完全可以修改现有的物  
品或是进行全新的设计。
