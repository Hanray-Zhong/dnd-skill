# 伊路斯坎人 Illuskan

伊路斯坎人是高个的白种人，他们长着蓝色或蓝灰色的眼  
珠，且大多长着鸦黑色的头发。而那些居住在极北地区的同种  
人则长着金黄、红色或浅褐色的头发。
