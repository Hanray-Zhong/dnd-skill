# 双持客 Dual Wielder

你精通双持武器进行作战，并获得下列增益：  
• 当你两手各持用一把武器时，你的 AC 获得 +1 加值。  
• 你进行双持武器战斗时所持用的单手近战武器可以不具备轻  
型武器属性。  
• 你可以在正常只能拔出或入鞘一把武器时，同时拔出或入鞘  
两把单手武器。
