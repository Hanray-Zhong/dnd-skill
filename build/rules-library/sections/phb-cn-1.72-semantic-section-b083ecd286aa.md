# 黑暗视觉 Darkvision

奇幻游戏世界中的许多生物都拥有黑暗视觉，其中的地底  
生物则大多都拥有该感官。拥有黑暗感官的生物可将其身边特  
定半径范围内的黑暗视为等同于微光光照。从而使该范围内的  
黑暗环境只具有轻度遮蔽效果。不过，该生物在黑暗中不能辨  
别颜色，只能以灰度影像视物。
