# Members

NPC 也有可能加入冒险的队伍中，他们会想要分享战利  
品，并愿意承担同样的风险，或者他们也可能会因忠诚、感激  
和爱慕等关系而跟随冒险者们。这样的 NPC 将由你控制，或  
者你也可以将控制转交给玩家。不过即使某玩家控制着 NPC，  
你也要确保该 NPC 被描绘成一个独立的角色，而不仅仅是玩  
家为自己利益而操纵的一个仆从。  
任何与冒险者们相伴行动的 NPC 都视为队伍的成员，并  
一同分享所有的经验值。在决定战斗遭遇的难度时（见第 3  
章），也一定要包括所有的 NPC 队友。
