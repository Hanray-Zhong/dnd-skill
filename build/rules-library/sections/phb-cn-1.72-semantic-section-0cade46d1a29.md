# 快速建卡 Quick Build

你可以按以下建议快速创建一名战士。首先，决定你是使  
用近战武器还是远程武器（或是灵巧武器），并据此将你最高属  
性分配给力量或敏捷。次高属性分配给体质，或者智力（计划  
选择奥法骑士范型时）。然后选择士兵背景。
