# 趣味性战斗遭遇 Fun Combat Encounters

以下的特征可以为战斗遭遇带来更多乐趣与悬念：  
• 对角色们和其敌人同时造成固有风险的地形特征，比如一  
条磨损的绳桥和一滩绿软泥。  
• 造成高低变化的地形特征，比如陷坑、一堆空的板条箱、壁  
架和阳台。  
• 激发或迫使角色们和其敌人四处移动的特征，比如垂吊灯、  
油桶火药桶群，以及旋转的刀刃陷阱。  
• 敌人身处难以到达的地点或防御位置，因此通常有一定攻  
击范围的角色被迫在战场上来回移动  
• 不同类型的怪物混在一起
