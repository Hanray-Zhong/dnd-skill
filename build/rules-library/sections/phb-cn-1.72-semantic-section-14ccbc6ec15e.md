# 反应 Reactions

某些特殊能力、法术以及某种状况下会允许你执行一种称  
作反应的特殊动作。反应是对事件触发瞬间的一个即时回应，  
可以在你的回合或其他人的回合中发生。最普遍的反应范例即  
是借机攻击。  
从你执行一个反应起，直至你下一回合开始前，你都不能  
再执行任何反应。如果你的反应打断了其他生物的回合行动，  
则该反应结束后该生物还可以继续其回合行动。
