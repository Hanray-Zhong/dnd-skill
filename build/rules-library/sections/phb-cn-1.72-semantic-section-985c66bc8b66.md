# 惧怖收割 Grim Harvest

第 2 级时，你可以在用法术杀死敌人时汲取其生命能量。  
你每回合有一次机会，在以一个环阶不低于 1 环的法术杀死一  
个或多个生物时，可以恢复等于该法术环阶两倍的生命值。如  
果你使用的是死灵系法术，则其恢复的生命值为法术环阶的三  
倍。你以此杀死不死生物或构装生物时，无法从该特性获得任  
何益处。
