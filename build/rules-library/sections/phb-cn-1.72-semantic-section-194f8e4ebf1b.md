# 野性直觉 Feral Instinct

第 7 级时，你的直觉变的异常敏锐，从而使你骰先攻时具  
有优势。  
此外，如果你在战斗开始时被突袭但并未陷入失能，则你  
仍可以在你的第一回合正常行动。不过你必须在进行任何其它  
行动前进入狂暴。
