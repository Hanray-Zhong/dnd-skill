# 忠诚值 Loyalty Score

衡量一名 NPC 的忠诚度数值范围从 0 到 20。 NPC 的忠  
诚值最高值等于队伍所有冒险者中魅力值最高者的数值，其  
起始忠诚值是该分值的一半。如果该最高魅力值发生变化（比  
如对应的角色死亡或者离开团体）则必须相应的调整该 NPC  
的忠诚值。
