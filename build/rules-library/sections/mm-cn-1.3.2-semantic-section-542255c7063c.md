# 种类附标 Tags

一种怪物可能会具有一个或者多个种类标签，额外的种类附  
标会标注在基础种类标签后的括号中。例如，兽人的种类是类人  
生物（兽人）。特定的种类附标给指定的生物赋予额外的细分种  
类。附标本身不包含任何规则，但游戏中的某些物品（比如魔法  
物品）使用时会与附标产生关联。比如一把对恶魔有伤害特效的  
矛，其特效可以作用于任何有恶魔附标的生物。
