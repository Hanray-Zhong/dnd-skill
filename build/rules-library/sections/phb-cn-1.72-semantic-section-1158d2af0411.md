# 图拉米人 Turami

图拉米人大多在内海南岸航行，他们通常高个而健硕，长  
着深红褐色的皮肤，黑色卷发和黑眼珠。

恩贝罗 Umbero

莱娜 Jalana、路易莎 Luisa、玛尔塔 Marta、夸拉 Quara、瑟
