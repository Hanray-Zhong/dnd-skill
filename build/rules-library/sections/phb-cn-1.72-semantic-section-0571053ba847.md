# 激励 Inspiration

激励是一项由 DM 视情况运用的额外奖励规则，用以帮助  
角色在扮演中凸显其个性特点、理想、牵绊以及缺点。通过使  
用激励，在与乞丐王子 Beggar Prince 交涉时，你能因同情压迫  
者的个性而与之针锋相对；或是面对某个法术效应时，因你保  
卫家乡的牵绊而强行避开伤害。
