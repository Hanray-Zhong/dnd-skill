# 大环境

《玩家手册》《怪物图鉴》以及本书在讲述 D&D 世界如何  
运作时都套用了一个默认的设定。在一些现成的 D&D 设定里，  
与默认设定相近的有：被遗忘国度 Forgotten Realms、灰鹰  
Greyhawk、龙枪 Dragonlance 和密斯塔拉 Mystara，而与之相  
差甚远的则有：浩劫残阳 Dark Sun、艾伯伦 Eberron、鸦阁魔  
域 Ravenloft、魔法船 Spelljammer 和异度风景 Planescape。  
你在创作自己的世界时，还可以随意决定该世界呈现的风格。
