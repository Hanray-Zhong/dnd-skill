# 被遗忘国度 The Forgotten Realms

在被遗忘国度的世界中，有着数十位神祇受崇拜、信仰以  
及敬畏。至少三十个神祇在整个世界里广为流传，此外还有更  
多的地方信仰、部落崇拜、小型教团以及一些大宗教的支派。
