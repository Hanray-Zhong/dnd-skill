# 中甲运用 Moderately Armored

先决条件：轻甲熟练项  
你习得如何使用中甲和盾牌，并获得下列增益：  
• 你的力量或敏捷加 1，上限为 20。  
• 你获得中甲和盾牌的熟练项。
