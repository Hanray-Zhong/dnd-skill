# 原初道途 Primal Path

怒火在每个野蛮人心中燃烧，并助其成就伟业。而每个野  
蛮人对其怒火的源头有着不同的认知。某些人将内心积攒的痛  
苦、哀伤和愤怒锻造成钢铁般强硬的狂怒；而另一些人则视怒  
火为图腾兽馈赠的精魄祝福。
