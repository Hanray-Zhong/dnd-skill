# 观察力 Observant

你能够迅速把握周遭环境的要点，并获得下列增益：  
• 你的智力或感知加 1，上限为 20。  
• 某生物在讲话时，若你可以看见目标的嘴且你可以理解其语  
言，则你就可以依靠读唇来解读目标正在讲什么。  
• 你的被动感知（察觉）和智力（调查）检定具有 +5 加值。
