# 激励 Inspiration

奖励激励是一种用来鼓励角色们进行扮演并承担风险的  
有效手段。如《玩家手册》中所述，获得激励的角色将获得显  
著的增益：得以在一次属性检定、攻击检定或豁免检定中获得  
优势。谨记一个角色同一时间至多只能保有一个激励。
