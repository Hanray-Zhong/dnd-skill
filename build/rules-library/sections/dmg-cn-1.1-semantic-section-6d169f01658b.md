# 水下能见度 Underwater Visibility

水下能见度取决于水体的清晰度和可用的光照。除非角  
色带有光源，否则参照表格“水下遭遇距离”来决定该角色进  
入遭遇事件时与事件的距离关系。  
**水下遭遇距离 Underwater Encounter Distance**

| 水体状况 | 遭遇距离 |
| --- | --- |
| 清澈的水，明亮光照 | 60 尺 |
| 清澈的水，微光光照 | 30 尺 |
| 浑浊的水或者无光照 | 10 尺 |
