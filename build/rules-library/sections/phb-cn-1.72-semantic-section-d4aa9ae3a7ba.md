# 雾遁 Misty Escape

第 6 级起，你在受到伤害时可以在一团迷雾中消失无踪。  
你受到伤害时，可以使用你的反应进入隐形，并传送到 60 尺  
内一处你能看见且未被占据的空间。直至你的下一回合开始，  
或直至你发动攻击或施法，你将维持隐形状态。  
你必须完成一次长休或短休后才能再次使用该特性。
