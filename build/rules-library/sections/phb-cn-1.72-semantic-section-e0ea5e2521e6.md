# 建议特征 Suggested Characteristics

智者们以其多年的研究为定义，而他们的性格也反映了这  
段学习生活。献身于学术研究的智者看重知识的价值——有时  
会以某个学识本身作代表，而有时则是该情报所引导出的其他  
理想。
