# 提夫林姓名 Tiefling Names

提夫林的名字主要分为三个大类。那些出生在其他文明里  
的提夫林其名字通常也反映着该文明的传统。有的提夫林名字  
则是从炼狱语演化而来，甚至经历了世代的传承，并同时反映  
着他们的邪魔血统。而那些努力寻找生存空间的年轻提夫林通  
常会采用一个名字来展现一种美德，或者表达出一种理想。有  
些提夫林会认为其名字意味着崇高的追求。而另一些则认为其  
名字预示着残酷的命运。
