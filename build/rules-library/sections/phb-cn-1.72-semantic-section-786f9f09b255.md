# 额外攻击 Extra Attack

当你从多种职业获得额外攻击特性时，此特性的效果并不  
能叠加。即你不能以此攻击两次以上，除非另有说明（如战士  
的额外攻击特性中的说明）。另外，当你具有额外攻击时，邪术  
师的魔能祈唤“饥渴魔刃”也不会给予你更多的攻击次数。
