# 装备 Equipment

你带着以下装备开始游戏，此外该角色还可以从其背景项  
中获得额外的起始装备：  
• （a）一把硬头锤或（b）一把战锤（拥有熟练项时可选）  
• （a）鳞甲，（b）皮甲或（c）链甲（拥有熟练项时可选）  
• （a）一把轻弩和 20 支弩矢或（b）任意简易武器  
• （a）一个祭司套组或（b）一个探索套组  
• 一个盾牌和一个圣徽
