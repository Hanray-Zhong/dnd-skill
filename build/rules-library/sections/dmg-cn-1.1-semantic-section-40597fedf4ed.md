# Organizations

神庙、公会、教团、秘密社团和学院等社会组织在每个文  
明中都是一些举足轻重的势力。它们的影响力可以覆盖复数  
的城镇，有时还会同时作为区域的政治权威。这些组织可以在  
玩家角色的生活中起重要作用，如同单独的非玩家角色一样  
成为主顾，盟友或敌人。角色加入组织后便成为比自身更大实  
体的一份子，并以此将冒险与广阔世界更紧密的联系起来。
