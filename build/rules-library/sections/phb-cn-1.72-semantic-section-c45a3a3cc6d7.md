# 战斗激励 Combat Inspiration

第 3 级起，你学会里如何激励他人作战。从你身上获得诗  
人激励的生物投掷武器伤害掷骰时，可以使用该激励骰并将其  
骰值加入本次伤害掷骰中。另外，从你身上获得诗人激励的生  
物被攻击时，该生物可以用它的反应使用该激励骰，并将掷骰  
结果加入到它对抗该次攻击的 AC 中，该特性可以使用于攻击  
检定揭示后，但必须在命中与否宣布之前使用。
