# 坚韧复仇 Relentless Avenger

第 7 级起，你超自然的专注力使你可以拦截敌人撤退。你  
以借机攻击中命中一个生物时，可以在该攻击后立刻移动至多  
相当于你速度一半的距离，本次移动是原反应的一部分。且本  
次移动不引起借机攻击。
