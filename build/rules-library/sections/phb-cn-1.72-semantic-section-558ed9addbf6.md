# 奥法骑士 Eldritch Knight

奥法骑士将战士的武术与严谨的魔法研究相结合。他们使  
用与法师类似的魔法技巧，但只专注于两个学派：防护和塑能。  
他们以防护法术保护自身，再以塑能法术同时攻击多个敌人，  
因而使其在战场上更加全面。奥法骑士只能掌握较少的法术，  
因此只需靠记忆完成而无需使用法术书。
