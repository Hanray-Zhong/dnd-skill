# 探索 Exploring

喜欢探索的玩家，总是想要体验那些奇幻世界必然给予  
的惊奇。他们想要知道下一个拐角，下一座小山后，究竟有些  
什么。他们喜欢翻找那些隐藏很深的蛛丝马迹和财宝。  
为吸引偏好探索的玩家，可以：  
• 留下暗示将要发生何事的线索。  
• 他们花时间探索后让他们找到些什么东西。  
• 给那些令人兴奋的景色充足的描述，并提供有趣的地图和  
小道具。  
• 在怪物身上布置可揭露的秘密，或可以了解的文化细节。
