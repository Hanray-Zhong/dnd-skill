# 以自身为目标 Targeting Yourself

如果法术的目标是由你指定的生物，则你也可以选择自身  
作为目标，除非法术描述中明确说明该目标必须是敌对生物或  
必须不是你自身。你身处自己所施展法术的效应范围之内时，  
也可以指定自身为法术目标。
