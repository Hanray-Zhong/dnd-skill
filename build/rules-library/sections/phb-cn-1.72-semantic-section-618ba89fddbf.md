# 矮人姓名 Dwarf Names

依照传统，矮人必须由氏族长老命名并重复使用代代相传  
的名字。矮人的名字不属于自己，而是属于氏族。若矮人让名  
字蒙羞，其名字将被氏族剥夺。依照矮人的律法，被剥夺名字  
的矮人禁止再使用矮人的名字。
