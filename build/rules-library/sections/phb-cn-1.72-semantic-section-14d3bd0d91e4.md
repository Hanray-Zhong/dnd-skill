# 怪物与死亡 Monsters and Death

大多数 DM 都会在怪物生命值降为 0 时直接宣告其死亡，  
而省略掉昏迷、濒死和死亡豁免等规则。  
不过某些大奸角和特殊 NPC 通常会是例外； DM 可能会让  
他们陷入昏迷，并沿用跟玩家相同的规则。
