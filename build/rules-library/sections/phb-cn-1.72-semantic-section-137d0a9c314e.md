# 神射手 Sharpshooter

你是熟练掌握了远程武器的使用方式，使看似不可能的射  
击都能成功命中。你获得下列增益：  
• 攻击最大射程内的敌人时，你的远程武器攻击检定不会具有  
劣势。  
• 你的远程武器攻击忽视半身掩护和四分之三掩护状态。  
• 你用拥有熟练项的远程武器发动攻击前，可以选择使该次攻  
击的攻击检定承受 -5 减值。若本次攻击中，则其伤害掷骰获  
得 +10 加值。
