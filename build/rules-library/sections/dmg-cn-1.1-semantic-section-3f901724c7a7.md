# 强冲 Overrun

生物试图强行穿越敌对生物所占空间时，移动者可以对  
该敌对生物执行强冲强行通过其关卡。作为一个动作项或附  
赠动作项，移动者必须进行一次力量（运动）检定，以对抗敌  
对生物的力量（运动）检定。尝试强冲的生物如果比敌对生物  
体型更大则其检定具有优势，如果更小则具有劣势。如果移动  
者赢得对抗，则它可以在本回合内移动穿过该敌对生物所占  
空间。
