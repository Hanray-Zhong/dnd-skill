# 哨兵 Sentinel

你的掌握的技术让你在击破敌人防御时占尽优势，并获得  
下列增益：  
• 你的借机攻击命中目标时，目标在本回合剩下时间内的移动  
速度降至 0。  
• 生物即使执行撤离动作离开你的触及范围也会引发你的借机  
攻击。  
• 处于你周边５尺范围内的生物对除你外的目标发动攻击后  
（且被攻击者没有这个专长），你可以用你的反应对该攻击者  
发动一次近战攻击。
