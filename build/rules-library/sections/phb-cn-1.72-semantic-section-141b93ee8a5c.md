# 精通至圣斩 Improved Divine Smite

第 11 级起，你体内充盈的公正之力使你的近战武器打击  
中携带着神圣的力量。当你使用近战武器命中一个生物时，该  
生物将额外受到 1d8 点光耀伤害。
