# 宝藏表 Treasure Tables

你可以根据怪物的挑战等级来随机分配宝藏。表格分为  
挑战等级 0 至 4，挑战等级 5 至 10，挑战等级 11 至 16 和挑  
战等级 17 或更高。你还可以使用这些随机表格来确定某个怪  
物携带了多少钱（相当于 D&D 中的零花钱）或在某个较大的  
宝库中发现的财富总金额。
