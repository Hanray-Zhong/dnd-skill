# 法术 Spells

一些魔法物品可以让其使用者从物品中施展法术。这些  
法师以法术的最低环阶施展，其不消耗使用者的法术位，也不  
需要任何构材，除非相应物品的描述中另有说明。这些法术使  
用它正常的施法时间、施法距离和持续时间，如果法术需要专  
注则该物品的使用者还必须对物品进行专注。许多物品（比如  
药水），可以直接跳过施法而直接赋予法术的效应并维持通常  
的持续时间。而一些特定的物品与该规则不同，会改变法术的  
施法时间，持续时间以及法术的其他内容。  

一些魔法物品（比如某些法杖）可能会在你用其施展法术  
时，还会要求你使用你自身的施法能力。此时如果你拥有超过  
一种施法能力，则可以自行选择使用其一。如果你没有施法能  
力（也许你是一名有着“使用魔法装置 Use Magic Device ”特  
性的游荡者），则此时你用该物品时的施法关键属性调整值为  
+0，同时你也可以使用相应的熟练加值。
