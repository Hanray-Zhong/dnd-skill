# 特性：研究员 Feature: Researcher

当你需要学习或是记起某段学识内容时，就算你并不清楚  
其具体信息，也总能知道从何处或何人身上着手获取。这些情  
报通常来自某个图书馆、抄写室、学院，甚至是其他某个智者  
或某个知道相关知识的人或生物。鉴于发掘多元宇宙最深的秘  
密有时会需要整趟的冒险甚至是整个的战役，你的 DM 可能会  
设定这段情报的所在是一个遥不可及的地方，或者直接将其定  
义为无法找到。
