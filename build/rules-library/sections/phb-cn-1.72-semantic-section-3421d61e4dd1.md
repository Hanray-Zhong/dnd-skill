# 宁神境 Tranquility

第 11 级起，你可以进入一种特殊的冥想状态，使浑身环  
绕着和平的灵光。完成长休后，你将获得法术庇护术 sanctuary  
的效应，其效应持续至你再次开始长休之前（该法术效应可以  
如常被提前终止）。该法术效应的豁免 DC 等于 8 ＋你的感知调  
整值＋你的熟练加值。
