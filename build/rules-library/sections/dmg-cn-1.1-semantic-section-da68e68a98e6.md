# 扮演 Acting

喜欢扮演的玩家，常常把自己代入角色，并以其角色的腔  
调说话。作为角色扮演的衷心爱好者，他们会乐于与 NPC、怪  
物以及队友们进行互动。  
为吸引偏好扮演的玩家，可以 :  
• 给他们发展角色个性和背景的机会。  
• 让他们经常和 NPC 互动。  
• 在战斗遭遇中增加扮演元素。  
• 将其角色的背景元素融入你的冒险中。
