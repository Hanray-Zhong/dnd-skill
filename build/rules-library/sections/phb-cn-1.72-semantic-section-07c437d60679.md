# 短休 Short Rest

短休是一段短暂的休整时刻。在至少 1 小时的短休时间内，  
各角色只进行安静的活动，诸如饮食、阅读、护理伤口等。  
完成短休时，角色可以花费一粒或多粒生命骰来恢复自身  
生命值，直至花光所有生命骰为止（生命骰的总数等于角色的  
等级）。每一粒生命骰的结果加上角色的体质调整值，即为该粒  
生命骰恢复的生命值（总数至少为 0）。每掷完一粒生命骰，该  
角色都可以选择是否花费更多生命骰来恢复生命。一个角色已  
花费的生命骰，可以通过完成一次长休来恢复，其具体规则如  
下文所述。
