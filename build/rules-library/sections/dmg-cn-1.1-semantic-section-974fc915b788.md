# 第1章你的世界

你的世界即是你战役的设定，是其冒险发生的所在地。即  
使直接使用现有设定（如被遗忘国度 Forgotten Realms），你  
将冒险设置于此，创作其中的角色以及依你的战役对其更改  
时，该设定就成了你自己的世界。本章主要内容，便是讲述如  
何建立你的世界以及如何在其中创作战役。
