# 吟游诗人学院 Bard College

吟游诗人之道也是交际之道。诗人们互相之间交换曲目和  
故事，吹嘘自己的造诣，并分享所得的知识。他们建立起架构  
松散的协会（即所谓的诗人学院），以此促进诗人团体的发展和  
维持他们的传统。
