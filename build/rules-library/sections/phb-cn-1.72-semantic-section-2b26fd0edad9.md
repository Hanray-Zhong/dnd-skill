# 快速建卡 Quick Build

你可以按以下建议快速创建建一名邪术师。首先，将你的  
最高属性分配给魅力，次高分配给体质。然后选择骗子背景。  
最后，选择戏法魔能爆 eldritch blast 和冻寒之触 chill touch，再  
选择 1 环法术魅惑人类 charm person 和巫术箭 witch bolt。
