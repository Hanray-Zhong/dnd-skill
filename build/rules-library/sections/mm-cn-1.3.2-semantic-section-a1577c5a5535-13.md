# 巢穴动作 Lair Actions

先攻轮到 20 时（出现等值时视为后手），龙可以执行一个巢  
穴动作并产生下列效应其一。它不能在连续两轮里重复使用同一  
种效应：  
• 银龙如同施展法术云雾术 fog cloud 般制造一团浓雾。该雾团  
持续直至下一轮先攻轮到 20。
