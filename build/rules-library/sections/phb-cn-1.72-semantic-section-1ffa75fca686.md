# 使用激励 Using Inspiration

你获得的激励，可以用于你的一次攻击检定，豁免检定或  
属性检定。使用激励可以使你的该次掷骰具有优势。  
另外，你所拥有的激励可以使用在其他玩家身上，用以协  
助其更好的扮演角色，或是用于一个巧妙的时机，又或者只是  
用来让游戏显得更有意思。当你觉得另一位玩家角色的行为让  
故事发展变的更欢乐更有趣时，你可以考虑将自己的激励给予  
该角色以推动故事发展。
