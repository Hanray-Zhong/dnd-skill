# 运动健将 Remarkable Athlete

第 7 级起，你可以将一半的熟练加值（向上取整）加在你  
不包含熟练加值的任何力量、敏捷或体质检定上。  
另外，当你助跑跳远时，你能跳出的距离增加等同于你力  
量调整值的尺数。
