# 不灭哨卫 Undying Sentinel

第 15 级起，你生命值降至 0 点，但尚未被直接杀死时，  
可以选择让你的生命值降到 1 点而不是 0 点。你必须完成一次  
长休后才能再次使用该能力。  
此外，你不受任何衰老减益。也不会因为魔法效应而衰老。
