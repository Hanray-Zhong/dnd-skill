# 角色资料 NPC Statistics

给 NPC 赋予游戏资料时，主要有三种方式：只给 NPC 赋  
予少量必要的资料，为 NPC 创建一个怪物资料板，或者给 NPC  
赋予一个职业和等级。后两种方式需要一点补充解释。
