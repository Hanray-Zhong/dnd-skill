# 极效治疗 Supreme Healing

第 17 级起，当你需要用一个法术来掷一粒或多粒骰子计  
算你所恢复的生命值时，所有骰子将取其最高值。例如，法术  
为某一生物恢复 2d6 生命值，则其结果直接取 12。
