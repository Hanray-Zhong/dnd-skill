# 天气 Weather

你可以选择一项适合战役的天气或按表格“天气”进行掷  
骰，再适当按地形和季节作调整，以此确定某天的天气。  
**天气 Weather**

| d20 | 温度 |
| --- | --- |
| 1~14 | 当季正常气温 |
| 15~17 | 比正常温度低 1d4 × 10 华氏度 |
| 18~20 | 比正常温度高 1d4 × 10 华氏度 |
| d20 | 风 |
| 1~12 | 无风 |
| 13~17 | 微风 |
| 18~20 | 强风 |
| d20 | 降水 |
| 1~12 | 无雨 |
| 13~17 | 小雨或小雪 |
| 18~20 | 大雨或大雪 |
