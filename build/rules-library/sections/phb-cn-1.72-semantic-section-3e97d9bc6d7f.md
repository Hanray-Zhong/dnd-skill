# 休息 Resting

冒险者们就算有如神话英雄般神勇，也无法整日每时每刻  
的进行探索、社交、战斗等高强度活动。因此，他们也会需要  
休息 —— 花时间吃东西和补充睡眠，还要护理身上的伤痛，并  
理清心绪为施法做准备，以为未来的冒险做好准备。  
冒险者以及任何生物都可以在一日中任何时刻进行短休，  
以及以一次长休结束一日。
