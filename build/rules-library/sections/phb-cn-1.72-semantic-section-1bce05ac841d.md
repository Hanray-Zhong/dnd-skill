# 与目标间畅通无阻 Clear Path to the Target

指定目标时，其与你之间必须畅通无阻，因此目标不可以  
相对你处于全身掩护状态。  
如果你将法术效应范围的目标指定在你看不见的地方，而  
你和该地点之间存在障碍（例如一面墙），则法术的源点改成在  
该障碍靠近你的一边。
