# 叙事 Storytelling

喜欢叙事的玩家，会希望自己对故事有所帮助。他们喜欢  
让自己的角色深度投入所展开的故事中，他们会喜欢那些和  
离奇情节相关联，又能够推动剧情的遭遇。  
为吸引偏好叙事者，可以：  
• 使用其角色背景来帮助塑造战役故事。  
• 确保冒险遭遇会以某种方式推进故事。  
• 让各角色的行动协助引导未来事件。  
• 给予 NPC 们赋予可供冒险者们深挖的理想、牵绊和缺点。
