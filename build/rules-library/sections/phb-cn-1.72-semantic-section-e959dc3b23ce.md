# 其他隐士 Other Hermits

这里所述的隐士背景特别之处是其设定了一个避世研习或  
祈祷的场所。如果你想要扮演一个在荒野离群索居的粗犷隐居  
者，也可以参考化外之民背景。而如果你想扮演的角色要更偏  
宗教色彩，则可以参考侍僧背景。或者你也可以扮演一名骗子，  
假装自己是一个睿智而神圣的人以骗取虔诚蠢蛋们为你提供帮  
助。
