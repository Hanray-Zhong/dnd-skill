# 快速建卡 Quick Build

你可以按以下建议快速创建一名术士。首先，将你的最高  
属性分配给魅力，次高属性分配给体质。然后选择隐者背景。  
最后，选择戏法光亮术 light，魔法伎俩 prestidigitation，冷冻  
射线 ray of frost，电爪 shocking grasp，以及 1 环法术护盾术  
shield 和魔法飞弹 magic missile。
