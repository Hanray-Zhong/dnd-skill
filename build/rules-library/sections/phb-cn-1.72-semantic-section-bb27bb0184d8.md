# 使用不同速度 Using Different Speeds

如果你有多种速度，例如步行速度和飞行速度，则你可以  
在移动中随时切换移动方式。切换移动方式时，新移动方式的  
速度必须先减去旧移动方式已移动的距离。得出的结果即为你  
还能移动的距离，如果结果为 0 或更少，则你在本次移动中无  
法再以新的移动方式进行移动。  
例如，如果你的速度为 30 尺，并因某法师的飞行术 fly 获  
得 60 尺的飞行速度。此时你可以先飞行 20 尺，再步行 10 尺，  
再跃起飞行 30 尺。
