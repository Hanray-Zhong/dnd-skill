# 附赠动作 Bonus Action

以附赠动作施法的法术特别迅捷。你可以在自已回合内以  
一个附赠动作施展该法术，前提是你在本回合内必须未执行任  
何附赠动作。此后在同一个回合里，你只能再施展一道施法时  
间为 1 动作的戏法，除此之外不能再施展其他法术。
