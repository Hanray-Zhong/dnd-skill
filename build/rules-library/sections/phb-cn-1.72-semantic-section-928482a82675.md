# 异界宗主 Otherworldly Patron

第 1 级时，你就跟某个异界的存在订下契约。你可以从至  
高妖精 Archfey、邪魔 Fiend、旧日支配者 Great Old One 等选  
项中选择其一。随后你将在第 1、第 6、第 10、第 14 级获得相  
应的职业特性。
