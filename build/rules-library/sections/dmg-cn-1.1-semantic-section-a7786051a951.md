# 规模 Size

在 D&D 世界中，占大多数的聚居地为环绕在大城镇周边  
的小村庄。农牧的村庄为城镇居民提供食物，以换取一些农夫  
们无法自给自足的商品。城镇是贵族们的根据地，他们管治着  
周边的地区并负责为周围村庄抵御进犯者的攻击。当地的领  
主或女领主有时也会居住于城堡塔楼或要塞之中，而其附近  
也并没有任何城镇。
