# 梁上君子 Second-Story Work

第 3 级选择此范型起，你获得比通常情况更快的攀爬速度，  
从而使攀爬不再消耗额外的移动力。  
此外，当你做一个有助跑的跳远时，跳远距离增加一定的  
尺数，其数值等于你的敏捷调整值。
