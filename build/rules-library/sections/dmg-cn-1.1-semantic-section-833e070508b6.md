# 地下城装饰 Dungeon Dressing

本节的诸表格提供了可放置在地下城中的杂项物品和特  
征点。地下城装饰可以帮助营造地下城的氛围，提供一些关于  
它的创造者和历史的线索，为设置唬人把戏和陷阱提供基础，  
或以此鼓励玩家进行探索。  
生成随机地下城装饰时，可以分别用下列的每个表格作  
一次掷骰：“声响”“空气”和“气味”。而本节的其他表格则  
可以随意进行多次掷骰，或直接从中选择合适的家具作摆设。
