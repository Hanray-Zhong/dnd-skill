# 声响 Sounds

地下城封闭的地理环境让其内的声响得以传播。开门的  
嘎叽声可以在通道中产生数百尺远的回响。大的噪音如锻炉  
的锤打声或战斗的交锋，甚至可以响彻整个地下城。很多地底  
生物运用这些声响定位猎物，或者用以警觉冒险队伍的入侵。
