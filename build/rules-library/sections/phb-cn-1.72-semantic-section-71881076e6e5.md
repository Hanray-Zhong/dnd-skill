# 武术范型 Martial Archetype

第 3 级时，你选择一种范型以体现你的战斗风格和技巧。  
你可以从诸如勇士 Champion、战斗大师 Battle Master、奥法骑  
士 Eldritch Knight 等范型中选择其一。随后，你将在第 3、第  
7、第 10、第 15、第 18 级获得所选范型的相应特性。
