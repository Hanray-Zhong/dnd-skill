# 声望降低 Losing Renown

与组织成员意见不合不足以引致在该组织中声望下降。  
然而，严重冒犯组织或其成员的罪行则会直接导致声望和阶  
级降贬。由此引致的声望变动其高低程度取决于该罪行的严  
重程度，且由你作最终判定。角色在一个组织中的声望不会降  
至低于 0。
