# 世界轴 The World Axis

这种宇宙图景中，物质位面与其回响位于两个对立界域  
之间。浮于上空的星界位面（或者众星之海 Astral Sea）包含  
着无数的神圣领域（外层位面）。沉于物质位面下方的元素混  
沌 Elemental Chaos 则是单一无差别的元素位面，所有元素都  
在其内互相糅合在一起。元素混沌的底部则是无底深渊 the  
Abyss，有如宇宙大画卷上撕裂的一个破洞。
