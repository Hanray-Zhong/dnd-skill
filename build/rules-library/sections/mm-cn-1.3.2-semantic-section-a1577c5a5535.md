# 巢穴动作 Lair Actions

拥有巢穴动作的传奇生物，可以在其巢穴中用这些魔法效应  
御敌。先攻轮到 20 时（出现等值时视为后手），该生物可以可以  
使用它其中一个巢穴动作项。它无法再失能或无法执行动作时完  
成该行为。受突袭时，它只能在自己本场战斗的第一个回合结束  
后，才能使用其传奇动作。
