# 德鲁伊语 Druidic

你习得德鲁伊语——即一种德鲁伊间的秘密语言。你可以  
说这门语言并用它留下隐藏的信息。懂得这门语言的人（包括  
你自己）会自动注意到此信息，而不懂此语言的人通过一次  
DC15 的感知（察觉）检定后可以注意到其存在，不过不能用非  
魔法手段读懂。
