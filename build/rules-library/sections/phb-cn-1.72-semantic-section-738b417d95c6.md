# 致命的猎人 Deadly Hunters

类人生物侵略者、狂暴的野兽与怪兽、可怕的巨人、致命  
的龙。作为荒野勇士的游侠们，专注于狩猎这些徘徊在文明世  
界边缘的危害之物。他们向掠食者们学习如何追踪猎物，并借  
助荒野中的灌木丛和碎石在阴影中潜行。游侠们通过特殊的战  
斗训练，使其在针对最具威胁敌人时可以惊醒更有效的应对方  
案。  
熟悉荒野的游侠们从中获得了利用大自然魔力施展法术的  
能力。他们的运作方式与德鲁伊类似，只是其法术与其实战能  
力相配，同样强调速度、隐匿以及狩猎。但每个游侠们的才能，  
却只能从死守边境的艰难险阻中磨练出来。
