# 选用规则：嗜血 Bloodlust

修罗场给伤害其他生物者提供奖励，并以此鼓励他们持  
续的去战斗。身处修罗场的生物将某一敌对生物的生命值降  
至 0 时，将获得等同于其自身生命值上限一半的临时生命值。
