# 选用规则：不朽盛怒 Immortal Wrath

约瑟园是被杀的英雄的家园，他们在这荣耀的战场上进  
行永恒的战斗。除构装生物和不死生物之外，任何生物被攻击  
或法术杀死后将在第二天黎明时恢复生命。该生物恢复所有  
生命值，并移除所有死亡前的所受的状态和苦痛。
