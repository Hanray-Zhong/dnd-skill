# 攻击 Attack

攻击动作是战斗中最常见的动作，包括了挥剑劈砍，弯弓  
射箭，或是直接徒手挥拳等动作。  
利用此动作，你可以发动一次近战或远程攻击。见“发动  
攻击”一节以获得更多跟攻击相关的规则。  
某些特性，例如战士的“额外攻击”特性，允许你用此动  
作发动多于一次攻击。
