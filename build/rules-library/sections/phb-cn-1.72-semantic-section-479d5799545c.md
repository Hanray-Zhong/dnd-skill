# 巨武器战斗 Great Weapon Fighting

双手持用一把近战武器发动攻击时，如果你的伤害掷骰掷  
出 1 或 2，则可以选择重掷。不过哪怕其仍是 1 或 2，你都必  
须接受重掷的数值。此外，该武器必须具有双手或两用属性。
