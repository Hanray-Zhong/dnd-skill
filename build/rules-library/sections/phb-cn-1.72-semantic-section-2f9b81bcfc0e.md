# 半兽人名字 Half-Orc Names

半兽人通常拥有符合其成长环境文化形式的名字。想要和  
人类打成一片的半兽人可能会将兽人名换成人类名。而一些拥  
有人类名的半兽人会为了更有威慑力而采用一个带喉音的兽人  
名。

Gell、哼克 Henk、豪格 Holg、伊姆吁 Imsh、凯斯 Keth、库  
斯克 Krusk、穆赫雷 Mhurren、隆特 Ront、夏普 Shump、梭  
克 Thokk
