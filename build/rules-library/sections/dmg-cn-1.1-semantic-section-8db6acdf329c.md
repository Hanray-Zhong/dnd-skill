# 以太位面遭遇 Ethereal Plane Encounters

以太边界中遭遇的大多数生物都是物质位面里感官或某  
些能力可以延伸至以太位面的物种（例如相位蜘蛛 phase  
spider）。幽魂 Ghost 也可以在以太与物质位面间自由切换。  
而在深层以太中，则大多会遭遇到其他的旅行者，尤其是  
来自内层位面的旅者（比如元素生物、巨灵 genie 和火蜥蜴  
salamander），偶尔还会遇上天界生物、邪魔或是精类生物。
