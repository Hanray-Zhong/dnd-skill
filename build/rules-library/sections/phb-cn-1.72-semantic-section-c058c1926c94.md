# 原初道途 Primal Path

第 3 级时，你选择一种道途来塑造你狂怒时的特质。你可  
以从狂战士 Berserker 和图腾武者 Totem Warrior 中选择其一。  
随后，你将在第 3、第 6、第 10、第 14 级时获得所选道途的相  
应特性。
