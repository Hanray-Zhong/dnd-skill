# 荒野形态 Wild Shape

第 2 级起，你可以用动作以魔力变化为曾见识过的野兽形  
态。该特性可以使用两次，且在完成一次短休或长休后，你将  
重新获得所有消耗掉的荒野形态次数。  
你的德鲁伊职业等级决定了你可以变化的野兽种类，你可  
以变化成任意没有飞行或游泳速度且挑战等级为 1/4 或更低的  
野兽形态。
