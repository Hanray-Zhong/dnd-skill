# 设计非玩家角色

一群开发妥当的 NPC 是最能让冒险与战役真实生动的好  
材料。话虽如此，游戏中的 NPC 其实不太需要像小说或电影  
中那些精心制作的角色一样复杂。大多数 NPC 在战役中都只  
是作为小角色，冒险者们才是其中的主角。
