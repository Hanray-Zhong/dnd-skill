# 异界神侍 Planetar

异界神侍是它所服侍之神的武器，是神之权威的具象化体现。  
一名异界神侍可以降下雨水缓解旱情，也可以召来虫灾吞噬农田。  
异界神侍以其天界之耳辨别一切谎言，用其光耀之眼使一切欺瞒  
之象无所遁形。  
异界神侍浑身无毛发而肌肉强健，长着散发微光的绿色皮肤  
和白色羽翼。它们比大多数类人生物更高大，并以优雅之姿挥舞  
着巨大的剑。异界神侍有时会依其神祇的意被派遣至强大凡人身  
边协助其执行与善良有关的事务，而它们尤其喜欢借此与邪魔展  
开战斗。
