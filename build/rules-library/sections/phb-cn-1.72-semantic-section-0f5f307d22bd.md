# 自恃而多疑 Self-Reliant and Suspicious

提夫林小范围聚集在人类的城镇中，通常都是最恶劣的住  
所，其中很多人长大后成为了骗子、窃贼或是罪犯头目。他们  
有时也会混迹在某些聚居地里其他少数族裔之中，以期获得更  
多的尊重。  

由于没有祖国后盾，提夫林们都懂得必须亲自找寻自己在  
世上的立身之道，而为了生存还要让自身足够强大。他们不会  
很快相信那些宣称是朋友的人，但当提夫林的伙伴展示出信任  
时，提夫林也会回报以同样的信赖。一旦提夫林效忠于某人，  
他们就是一生中坚实的伙伴和队友。
