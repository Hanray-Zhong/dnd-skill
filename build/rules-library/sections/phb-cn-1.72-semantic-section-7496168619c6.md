# 施法关键属性 Spellcasting Ability

你的魔力源于你注入音乐或演说中的心灵力量，因此魅力  
是你施展吟游诗人法术的关键属性。每当你的诗人法术需要施  
法关键属性时均指向你的魅力值。而你诗人法术的豁免 DC 和  
攻击检定，则使用你的魅力调整值。  
如果你已知法术列表中的某法术带有仪式标签，则你可以  
用这些法术进行仪式施法。
