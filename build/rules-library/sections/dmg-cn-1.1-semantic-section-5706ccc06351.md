# 使用微缩模型 Using Miniatures

在战斗中，玩家通常可以依赖你的描述来想象他们的角  
色与周围环境和敌人的位置。然而，一些复杂的战斗可以用视  
觉辅助工具更容易的进行表达，其中最常见的就是使用微缩  
模型和格子。如果你喜欢建造地形模型，建造三维的地下城或  
者在乙烯大垫子上画地图，你也应该考虑使用微缩模型。  
《玩家手册》中提供了使用微缩模型和格子的一些简单  
规则。本小节则为其提供一些扩展内容。
