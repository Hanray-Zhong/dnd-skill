# 创造奴仆 Create Thrall

第 14 级时，你从获得以宗主的异界魔法感染类人生物心  
智的能力。你可以用你的动作触碰一个处于失能状态的类人生  
物。该生物随即陷入受你魅惑的状态，直至被施以法术移除诅  
咒 remove curse、其魅惑状态被移除，或直至你再使用此特性。  
只要你和你的奴仆处于同一位面，你就可以通过心灵感应  
与你的奴仆进行交流。
