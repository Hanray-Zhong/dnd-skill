# 建议特征 Suggested Characteritics

成功的艺人能够唤起并抓住观众的注意力，所以他们倾向  
拥有张扬或亲和的特征。他们对浪漫趋之若鹜，并对艺术和审  
美的标准坚持高傲的理想。

|  | 息。 |
| 3 | 我是无可救药的浪漫病，总是在找“有缘人”。 |
| 4 | 我周围的人都不会生气太久，因为我总能缓和紧张的气 |

| 7 | 我是完美主义者。 |
| 8 | 我的情绪和思想变得和弹琴轮指一样快。 |
