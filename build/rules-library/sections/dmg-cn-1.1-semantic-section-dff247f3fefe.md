# 受害者 Victim

想想受害者与反派的关系。尽管你可以创建一个不存在  
这种关系的精彩剧情，但在神秘事件中发现 NPC 们其实与罪  
案相关的转折总会是令人兴奋的剧情部分。随机杀戮可能同  
样神秘，但它总是缺乏那种情感上的联系。  
你还可以设定受害者与一个或多个冒险者之间有所关联。  
万无一失的让冒险者们融入神秘事件的方法，便是将其拖入  
其中（包括让其本身陈伟嫌疑人），也即是让角色们相熟的人  
成为受害角色。
