# 复仇之誓 Oath of Vengeance

复仇之誓，是立誓惩戒那些严重罪行的庄严承诺。当邪恶  
势力屠杀无助居民，当所有民众背离神祇意志，当某个盗贼行  
会过于强横霸道，当恐怖巨龙横行乡野——每当这种时刻，复  
仇之誓的圣武士就会出现来拨乱反正。这些圣武士（有时也称  
作复仇者或黑骑士）即使牺牲自己的纯洁，也一定要伸张正义。
