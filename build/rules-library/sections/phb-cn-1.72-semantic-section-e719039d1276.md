**服务 Services**

| 服务 | 工钱 |
| --- | --- |
| 计程客车 coach cab |  |
| 城际 between towns | 3 cp 每里 |
| 城内 within a city | 1 cp |
| 雇工 hireling |  |
| 熟练雇工 skilled | 2 gp 每日 |

某些与熟练项相关的工作（包括武器、工具、技能），雇以  
工作的人员同样视为熟练雇工：比如佣兵、工匠、文员等。表  
中所列出的工价只是其下限，某些技能精湛的专家可能会向你  
要求更高的薪酬。新手雇工则只能从事不需要特定技能的工作，  
包括苦力、送货员、女仆等工人工作。
