# 变体：自定义属性值 Variant: Customizing Ability Scores

你的地下城主可以选择启用该变体规则，使你可以选用另  
一种方式分别选择你所创建角色的属性值。  
你获得总计 27 点可花费的点数用于兑换各属性值，每个  
属性值的花费在“属性值花费点数”表中显示。例如，一个属  
性值 14 需要花费 7 点进行兑换。以该方式能兑换到的属性值  
在加入种族增益前其最值为 15。而你也不能拥有低于 8 的属性  
值。  
这种决定属性值的方式可让你得到三个相等的高数值和三  
个相等的低数值组成的组合（15、 15、 15、 8、 8、 8），或一个  
平均值更高但各数值几乎相等的数值组合（13、 13、 13、 12、  
12、 12），或是任何这两个极端之间的数值集合。
