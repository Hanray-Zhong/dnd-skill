# 快速建卡 Quick Build

你可以按以下建议快速创建一名游侠。首先，将你的最高  
属性分配给敏捷，次高分配给感知。（一些注重双持武器战斗的  
游侠其力量该高于敏捷。）其次选择化外之民背景。
