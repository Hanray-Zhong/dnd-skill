# 非公开名单 Hidden List

许多 DM 在一份不对玩家公开的名单上跟进先攻顺序：  
通常就是一张在 DM 帷幕后的纸或平板电脑上的电子表格。  
这个方法可以帮你跟进未一些尚未暴露存在的参战者，你还  
可以使用先攻名单来记录当前的怪物的生命值，以及其他一  
些有用的笔记。  
这种方法的缺点就是你每轮都要提醒相应的玩家他的回  
合开始与结束。
