# 驻防 Garrisons

城堡和塔楼堡垒需要雇佣士兵（使用《怪物图鉴》中的老  
兵 veteran 和警卫 guard 资料）来作其守卫。路边旅馆、哨站  
和碉堡、宫殿和神庙则可以依赖于经验不高的护卫（使用《怪  
物图鉴》中的警卫 guard 资料）。这些整备好的武者便是物业  
所需熟练雇工中的一大部分。
