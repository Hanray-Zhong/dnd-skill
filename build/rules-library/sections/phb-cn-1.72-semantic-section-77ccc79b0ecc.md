# 真实视觉 Truesight

具有真实视觉的生物可以在特定距离内看透普通或魔法的  
黑暗；看破隐形的生物和物件；对侦察视觉幻象的豁免皆直接  
成功通过；看穿变形生物或用魔法转换形态生物的原来形态；  
相应的生物甚至可以同时看到以太位面。
