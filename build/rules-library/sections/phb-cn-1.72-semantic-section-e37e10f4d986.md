# 修行宗派 Monastic Traditions

多元宇宙里的众多修道院中，有三个流派流传最为深广。  
大多数的修道院会一味的精进某一流派的技艺，而某些同时精  
通三派技艺的修道院则广收门徒，并对门下武僧们因材施教。  
所有三个流派都源于同一技艺基础，随着门徒的成长差异最后  
才分宗立派。因此，一个武僧必须达到第 3 级时，才能在这些  
宗派中选择其一。
