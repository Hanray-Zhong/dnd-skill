# 触发陷阱 Triggering a Trap

大多数的陷阱会在一名生物踏上某处或者碰到某物时触  
发，而该物或该处通常都是陷阱制作者想要保护的对象。通常  
的触发条件包括踩到压力板或踩到地板虚假的部分，拉扯到  
拌线，转动门把，或是对门锁使用错误的钥匙。魔法陷阱经常  
设计成当一名生物进入某区域或是触碰某物件时自行启动。  
有些魔法陷阱（例如守卫刻文或魔法徽记）会有更复杂的触  
发条件，包括避免陷阱激活的口令。
