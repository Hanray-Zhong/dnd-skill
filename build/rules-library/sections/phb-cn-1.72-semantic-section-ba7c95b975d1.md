# 远程攻击 Ranged Attack

你发动的一次远程攻击，包括用弓或弩发射一发弹药，丢  
出一把飞斧，或者用其他投掷物投向一定距离外的敌人。一个  
怪物则可能会甩尾射刺来作远程攻击。而很多法术也会发动一  
次远程攻击。
