# 附录：状态

A Conditions  
生物的能力受状态的影响。特殊状态可能来源于法术、职  
业特性、怪物能力等因素。大部分状态对角色不利，例如目盲。  
但也有少数状态对角色有利，例如隐形。  
一种状态的持续时间要么延续到它被解除（例如，倒地状  
态可以通过起身解除），要么由引发状态的效果决定。  
当复数的效应使一个生物承受同种状态时，每种效应所引  
发的状态需分别计算其持续时间。但同时受到复数的同种状态  
并不会加强该状态的效果。此外，一个生物只可能处于或不处  
于某种状态。
