# 巫师杀手 Mage Slayer

你拥有一套对付施法者的近身战法，并获得下列增益：  
• 你周边 5 尺范围内的一个生物施展法术后，你可以用你的反  
应对该生物发动一次近战武器攻击。  
• 当你对一名正专注法术的生物造成伤害时，该生物进行维持  
本次专注的豁免检定时具有劣势。  
• 你为抵抗身边５尺范围内生物对你施展的法术而进行的豁免  
检定具有优势。
