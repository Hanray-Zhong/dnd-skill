# 游荡者范型 Roguish Archtype

第 3 级时，你选择学习一种特定的战斗范型。你可以从盗  
贼 Thief、刺客 Assassin 或者诡术师 Arcane Trickster 中选择其  
一。随后，你将在第 3，第 9，第 13、第 17 级时获得所选范型  
的相应特性。
