# 建议特征 Suggested Characteristics

化外之民时常被城市居民当作粗鲁蠢笨的家伙，而无法在  
城市生活中获得尊重。而大多数的化外之民则会将自身与部族，  
氏族，家族或是大自然的联系视为自身的牵绊。
