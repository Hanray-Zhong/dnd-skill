# 使用物件 Use an Object

你通常会在做某件事的同时顺便跟一个物件进行互动（例  
如攻击同时拔出剑）。而某些物件的互动则会需要用动作完成，  
此时则需要你执行使用物件动作。当你想在一回合内操作多于  
一个物件时，也可以用该动作使用第二个物件。
