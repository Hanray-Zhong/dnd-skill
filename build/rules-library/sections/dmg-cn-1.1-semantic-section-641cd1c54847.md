# 残酷现实 Gritty Realism

该变体使用 8 小时的短休时间和 7 日的长休时间。以此  
作为玩家们在战役战斗中自行决断利弊的中断点。角色们无  
法一时承受过多的战斗任务，因而所有冒险都必须先作好谨  
慎的计划。  
这种方法鼓励角色们把时间花在地下城中。比较适合那  
些强调阴谋斗争、政治和 NPC 交互的战役，以及那些战斗状  
况较少或是鼓励绕开战斗而非一往无前的战役。
