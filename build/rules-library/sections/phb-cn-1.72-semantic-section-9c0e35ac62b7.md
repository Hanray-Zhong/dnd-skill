# 诡术师 Arcane Trickster

一些游荡者会学习幻术系和附魔系的诡术，以这些魔法来  
提高自己已经相当老练的隐匿和灵动水平。这些游荡者包括扒  
手和窃贼，也包括一些恶作剧者或离间者，也有相当一些成为  
冒险者。
