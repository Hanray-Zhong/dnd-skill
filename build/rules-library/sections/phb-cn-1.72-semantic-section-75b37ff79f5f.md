# 泰瑟尔人 Tethyrian

泰瑟尔人广泛分布在费伦大陆西岸的剑湾 Sword Coast 地  
区，他们长着中等尺寸的体格和身材，以及黝黑的皮肤，在北  
部地区的同种人肤色会稍浅。他们的发色和瞳色各种各样，但  
通常都是褐发蓝眼。泰瑟尔人大多会使用琼达斯人的命名方法。
