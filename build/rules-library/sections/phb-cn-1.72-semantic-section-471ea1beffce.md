# 对应职业的起始财富Starting Wealth by Class

你可以设定你的角色如何得到这些起始装备。它可能是一  
笔遗产，或是该角色在其的成长时期买到的商品。你可以带着  
一把武器，一具护甲和一个背包以作为曾经服役的军需。或者  
说这些装备根本就是自己偷来的。一把武器可以是家族的传家  
宝，世代相传直到最终由你的角色继承并以此追寻某位先祖的  
冒险足迹。
