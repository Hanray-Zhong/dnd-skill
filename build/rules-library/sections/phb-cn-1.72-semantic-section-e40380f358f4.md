# 牧养之乐 Pastoral Pleasantries

半身人大都群居成小型的平和社区，其中还包括有大片的  
农场和井然的果园。除了这些宁静的郡县，他们绝少建起自己  
的王国或是占地为王。他们并不承认同族中的贵族或王族，不  
过依然会仰赖各家长者的指引。因而其家族的传统生活并不受  
王国的兴亡影响。  
很多半身人居住在其他种族群体中，并通过辛劳和忠诚赢  
取安稳富足。另一些半身人社群则奉行游牧生活。他们开著篷  
车或篷船在各地流浪，且从不久留。
