# 创作新种族 Creating a New Rage

当从零开始创作一个种族时，你可以先从其故事着手。把  
你的创作和你世界中的其他种族进行比较，并随意以其他种  
族的特质做借鉴。作为范例，参考下列的阿斯莫 aasimar ——  
一个带着天界生物遗产，与提夫林 tiefling 有些相似的种族。
