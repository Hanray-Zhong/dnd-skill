# 超自然赠礼 Supernatural Gifts

超自然赠礼是由强大魔力存在或原力赋予的特殊奖励。  
这类超自然赠礼有两种形式：祝福和护咒。祝福通常由神灵或  
类神存在所赐。而护咒则通常是某强大精魂，某远古魔法区域，  
或某个传奇生物的作用。与魔法物品不同，超自然赠礼不是物  
品，也不需要同调。它可以赋予角色可以单次或多次使用的非  
凡能力。
