# 无底深渊 The Abyss

无底深渊 Abyss 具现了一切的悖逆、恐怖和混乱。它几  
乎无尽的层级螺旋向下，形成一片愈加可怕的形态。  
深渊的每一层级都有各不相同的可怕环境。虽然没有哪  
两层长的一样，但却都是一样的严酷而不适宜居住。每一层都  
反映了深渊的混乱本质。事实上，人们在位面中看到或接触到  
的大部分东西，似乎都处在腐朽、破碎或堕落的状态中。
