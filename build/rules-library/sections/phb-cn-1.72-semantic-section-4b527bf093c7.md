# 引导神力：导引打击 Channel Divinity: Guided Strike

第 2 级起，你可以用引导神力特性作出精准的打击。你在  
进行攻击检定时，可以使用引导神力令该次检定获得 +10 加值。  
你可以在看到掷骰结果后 DM 公布是否命中前，决定是否使用  
该特性。
