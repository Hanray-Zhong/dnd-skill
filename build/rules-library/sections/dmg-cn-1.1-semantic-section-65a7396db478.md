# 技能变体 Skill Variants

技能可以令角色在进行属性检定时得到熟练加值，决定  
加值情况的技能涉及六种基本属性的多个不同方面。例如体  
操 Acrobatics 与隐匿 Stealth 便是敏捷属性下的两个分项，角  
色能够选择专攻其中一种或两者兼备。  
你可以摒弃技能并改用以下变体中的一项。无论你如何  
选择，其关键在于是否适合于战役。
