# 生还者 Survivor

第 18 级时，你持续战斗的能力达到巅峰。你每回合开始  
时如果生命值不到上限的一半，则你恢复一部分生命值，其数  
值等于 5 ＋你的体质调整值。你生命值为 0 时不能以此获益。
