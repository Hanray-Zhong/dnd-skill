# 盲视 Blindsight

具有盲视感官的角色即使不靠视力也可以感知身边特定半  
径范围内的环境。无眼的生物（如泥怪），以及拥有回声定位或  
高敏感官的生物（如蝙蝠和真龙），都具有这种感官。
