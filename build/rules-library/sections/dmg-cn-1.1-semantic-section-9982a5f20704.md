# 选用规则：野兽变形 Beast Transformation

旅行者在该位面杀死一头野兽时，该杀戮者必须进行一  
次 DC10 的魅力豁免，豁免失败者将变身为被杀的野兽（如同  
法术变形术 polymorph）。处于该形态时，该生物保留着其原  
来的智力值和说话能力。每次完成长休后，被变形的生物都可  
以再进行一次该豁免。豁免成功则该生物恢复其真实形态。三  
次豁免失败者只能通过法术移除诅咒 remove curse 或类似魔  
法才可逆转该效应。
