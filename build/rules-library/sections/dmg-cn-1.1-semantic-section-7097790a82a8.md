# 极乐境 Elysium

极乐境 Elysium 是无限仁慈的怜悯者之家，也是欢迎位  
面旅者前来寻求庇护的避难所。该位面的田园风光在大多数  
时候都闪耀着生命与美丽之光。人们在进入该位面时便被其  
安宁渗入骨髓与灵魂。这是个可以让人安心歇息的天堂，是快  
乐的眼泪在人们脸颊上闪亮的地方。
