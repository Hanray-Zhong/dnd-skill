# 现实史传奇幻神系 Fantasy-Historical Pantheons

凯尔特、埃及、希腊以及北欧神系是现实人类发展史上曾  
经真实存在的古老宗教。撇开其真实的历史脉络后，经过重新  
系统的整合，这些神袛刚好可以在 D&D 的游戏中使用。
