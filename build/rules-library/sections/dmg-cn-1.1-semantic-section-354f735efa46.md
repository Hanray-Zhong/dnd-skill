# 设置主线故事 Using an Overarching Story

以下介绍两个多年来启发了许多经典龙与地下城战役的  
主线任务范例。  
第一个例子中，冒险者的目标是积攒力量去对付一个具  
有世界级威胁的强大敌人。第二个例子中，他们的目标则是为  
了守护关心的人或物而必须摧毁任何对其造成威胁的东西。  
这实际上是从两个不同的角度来叙述同一个故事（此消彼长  
的善恶之争）。
