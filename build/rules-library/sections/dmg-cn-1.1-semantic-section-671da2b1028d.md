# 2. 创建局部地区 Create a Local Region

见本章前文的“绘制战役”小节所述，并依此以大本营为  
中心绘制一幅省区尺度的地图（1 六角格＝ 1 里）。以大本营  
为中心，为地图填充一天旅程可到达地区的内容（大概 25 到  
30 里）。在其内布置两个到四个左右的地下城或者类似的冒险  
区域。这种规模的地区应该有一个到三个左右，跟大本营相似  
的其他聚居地，当然也应该作一些适当的构思。
