# 选用规则：监狱位面 Prison Plane

没有人能轻易地离开卡瑟利。除法术许愿术 wish 之外，  
所有尝试离开该位面的魔法效果都会失效。通向该位面的传  
送门和门扉都只能实现单向传送。确实存在离开该位面的秘  
密方法，只是它们都被绝密的隐藏起来，并由致命的陷阱和怪  
物看守着。
