# 防守战术 Defensive Tactics

第 7 级时，你选择获得以下特性之一。  
冲出重围 Escape the Horde。 以你为目标的借机攻击具有  
劣势。  
多重防御 Multiattack Defense。 你被生物的攻击命中时，  
你在本回合内对抗该敌人所有后续攻击的 AC 获得 +4 加值。  
钢铁意志 Steel Will。 你对抗恐慌的豁免具有优势。
