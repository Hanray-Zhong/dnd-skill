# 移动与位置 Movement and Position

在战斗中，角色和怪物都在持续地运动，并利用位置和动  
作的变化使自己占据上风。  
你在自己回合内可以移动一段距离，其尺数最高等于你的  
速度。你可以在你的速度尺数以内随意花费你的移动力，并遵  
从下列的规则。
