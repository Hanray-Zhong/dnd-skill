# 粘土魔像 Clay Golem

由粘土塑造而成的笨重魔像在大多数人类体型的生物中算  
是鹤立鸡群。它长着人类的外形，但躯体比例又不尽相同。  
粘土魔像经常被一些带着伟大信仰的祭司有目的性的注入  
某些神圣馈赠。不过，粘土毕竟是非常脆弱的生命容器。魔像一  
旦出现破损，其内的元素精魄也会随之解放。这样的魔像甚至会  
变得随处横行并粉碎身边所有的东西，直到它被摧毁或完全修复  
为止。
