# 琼达斯人 Chondathan

琼达斯人是茶色皮肤的纤瘦民族，他们褐色头发的发色范  
围从接近金黄到接近乌黑。其中大部分人长着绿色或褐色的眼  
珠，只是这些特性并不十分普遍。琼达斯血统的人类支配着费  
伦大陆的中部，内海 Inner Sea 的周边地区。
