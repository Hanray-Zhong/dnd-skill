# 变体公会工匠：公会商人 Variant Guild Artisan: Guild Merchant

跟工匠公会不同，你所属的公会的成员主要是商人，商队  
车主或商店主。你并不会自己制作物品，只是通过买入售出其  
他人的作品过活（或者买卖制造业者生产所需的原材料）。你的  
公会可能是一个大型的商人财团（或家族），而其影响可能跨越  
相当大的地域。你可能会使用船只，货车或商队在各个地区之  
间运输商品，或者直接从旅行商人处进货再放在你自己的小店  
中售出。有些时候，旅行商人的生活也许会让其冒险生涯走得  
比工匠更远。  
你可以用领航工具的熟练项，或者掌握额外一门外语来替  
换工匠工具的熟练项。还可以用一头骡子或者一辆二轮货车代  
替起始工具中的工匠工具。
