# 作案手法 Criminal Specialty

违法犯罪的行为五花八门，而在盗贼公会或类似的犯罪组  
织中，每个成员也有着不同的专职分工。即便是那些游离于组  
织之外的罪犯，也会对某些特定的罪行更为偏爱。选择你在犯  
**罪生涯中扮演的角色，或者依据下列表格进行随机投骰。**
