# 饰品 Trinkets

你在创作角色时，可以参照“饰品”表骰得一件饰品——  
一件被神秘轻微点化的物品。 DM 有时候也会用到本表格，比  
如用来点缀地下城的房间，或者用来装满某个生物的口袋。
