# 随机陷阱 Random Reaps

如果你需要随手的陷阱或要在地下城中放置随机陷阱，  
可以使用第 5 章“冒险环境”中提到的陷阱范例或下列表格。  
如果你选择使用表格，那么先使用表格“陷阱效应”和“陷阱  
触发”来设定陷阱的类型，再使用表格“陷阱危害度”来决定  
它的致命程度。关于陷阱危害度的更多信息，详见第 5 章。  
**陷阱触发 Trap Trigger**

| d6 | 触发 |
| --- | --- |
| 1 | 踩踏（地板，楼梯） |
| 2 | 走过（门道，过道） |
| 3 | 触碰（门把手，雕像） |
| 4 | 打开（门，宝箱） |
| 5 | 观看（壁画，奥秘符号） |
| 6 | 移动（手推车，石砖） |
**陷阱危害度 Trap Damage Severity**

| d6 | 危害度 |
| --- | --- |
| 1~2 | 挫折 setback |
| 3~5 | 危险 dangerous |
| 6 | 致命 deadly |
