# 战技专家 Martial Adept

接受战技训练后，你可以使用一些独特的战技。你获得下  
列增益：  
• 你选择习得战士战斗大师范型战技列表中的两个战技。如果  
所习得的战技需要目标进行豁免检定来抵抗战技效果，则其  
豁免 DC 等于８＋你的熟练加值＋你的力量或敏捷调整值（自  
选）。  
• 你获得一枚 d6 的卓越骰（该骰可加到任何你以其他方式获  
得的卓越骰中）。此卓越骰可用于启动你的战技。此卓越骰一  
经使用即消耗，并在完成短休或长休后恢复。
