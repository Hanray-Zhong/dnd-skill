# 快速建卡 Quick Build

你可以按以下建议快速创建一名游荡者。首先，你将最高  
属性分配给敏捷。如果你想精于调查或者打算选择诡术师范型，  
则将次高属性分配给智力。如果你打算着重于骗术或者社交，  
则将次高属性分配给魅力。然后，选择骗子背景。
