# 幽影通道 Shadow Crossings

幽影通道与妖精通道相似，是物质位面与堕影冥界之间  
边界薄弱之处，以至于一些生物可以从该穿越于两个位面之  
间。尘土飞扬的地穴角落里可能存在一条幽影通道，一处打开  
的陵墓也有可能。幽影通道是一片阴暗之地，此间徘徊着精魂  
与死亡的恶臭，比如战场、墓地和陵墓。他们只在黑暗中显现，  
当感觉到光明的接触时便会立即关闭。
