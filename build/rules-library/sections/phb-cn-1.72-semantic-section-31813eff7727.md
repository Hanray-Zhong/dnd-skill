# 装备 Equipment

你带着以下装备开始游戏，此外该角色还可以从其背景项  
中获得额外的起始装备：  
• （a）一把巨斧或（b）任意一把军用近战武器  
• （a）两把手斧或（b）任意一把简易武器  
• 一个探索套组和四支标枪
