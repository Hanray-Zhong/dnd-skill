# 护甲 Armor

除非一件护甲的描述另有说明，否则护甲必须着装才能  
让其魔法发挥作用。  
一些魔法护甲会指定其护甲类型，例如链甲或板甲。如果  
一件魔法护甲没有指定其护甲类型，则你可以随意或随机为  
其指定一个类型。
