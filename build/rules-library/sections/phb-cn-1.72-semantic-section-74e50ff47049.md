# 地城探索者 Dungeon Delver

由于对隐藏的陷阱和密门特别敏感，你获得下列增益：  
• 你为搜寻密门进行的感知（察觉）和智力（调查）检定具有  
优势。  
• 为躲避或抵抗陷阱而进行的豁免检定具有优势。  
• 你对陷阱所造成的任何伤害都具有抗性。  
• 你以快速步调旅行时无需承受通常情况下的被动感知（察觉）  
值的 -5 罚值。
