# 知识祝福 Blessing of Knowledge

在第 1 级时，你学会两门自选语言。你还从以下技能中选  
择两项加入你的熟练项中：奥秘、历史、自然、宗教。  
你进行关于所选两项技能的属性检定时，可以加上双倍的  
熟练加值。
