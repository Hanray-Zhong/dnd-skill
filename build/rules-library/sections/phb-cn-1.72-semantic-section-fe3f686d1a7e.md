# 变体水手：海盗 Variant Sailor: Pirate

你在由一个恐怖的海盗抚养长大，这个残忍的杀人犯教会  
了你如何在血腥而危险的世界中生存。期间，你沉溺于在公海  
上劫掠，并将那些无辜者送入海底。熟悉恐惧和杀戮滋味的你，  
成为了许多港口间流传的恶名。  
当决定在你的航海生涯中加入海盗元素时，则你可以用恶  
名特性（见边栏）代替船家路子特性。
