# 清晰的焦点 A Clear Focus on the Present

冒险发生于当下。补充一点点的历史有时也可以帮助故  
事情节发展，冒险者也许还会在冒险过程中发现一些有趣的  
传说。总之，你要让世界历史在当前的形势下清晰明了。一场  
冒险应该集中描述当前的状况——坏人们都在做什么，而冒  
险者们又如何参与到故事中，而不是处理过去所发生的事情。
