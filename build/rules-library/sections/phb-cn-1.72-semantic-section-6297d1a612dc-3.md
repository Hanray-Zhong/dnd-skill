# 戏法 Cantrips

第 1 级时，你选择两项德鲁伊法术列表中的戏法作为已知  
法术。在获得更高的德鲁伊等级后你还可以习得其它的戏法，  
具体数据参见“德鲁伊职业表”中“已知戏法”一栏。
