# 引导神力：毁灭狂怒 Channel Divinity: Destructive Wrath

第 2 级起，你可以用引导神力特性为自己装备无拘束的凶  
猛风暴之力。  
当你造成闪电或雷鸣伤害时，可以使用引导神力使该伤害  
的伤害掷骰直接取最高值而无需掷骰。
