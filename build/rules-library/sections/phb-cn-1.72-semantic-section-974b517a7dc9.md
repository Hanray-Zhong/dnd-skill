# 龙与地下城神系 D&D Pantheons

从充斥各种神灵的被遗忘的国度和灰鹰到有主导宗教的艾  
伯伦和龙枪， D&D 多元宇宙中的每个世界都有其特定神系。很  
多非人种族在不同的世界信仰着相同的神祇。例如在被遗忘国  
度、灰鹰和其他许多世界中的矮人都信仰摩拉丁 Moradin。
