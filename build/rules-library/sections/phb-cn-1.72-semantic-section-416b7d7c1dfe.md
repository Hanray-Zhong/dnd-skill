# 战斗动作 Action in Combat

你在自已回合执行动作时，可以选择以下动作选项之一，  
也可以选择你的职业特性、特殊能力所给予的动作，甚至可以  
选择一个你临时创作的动作。另外，很多怪物的动作选项都列  
明在其属性表中。  
当你想作出某个动作而规则里没有相关的说明时， DM 会  
告诉你该动作是否可行，以及你是否需要进行相关检定来决定  
动作的成败。
