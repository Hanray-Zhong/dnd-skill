# 经验值 Experience Points

经验值（XP）的数值基于怪物所拥有的挑战等级。通常， XP  
奖励会在怪物被击败时获得，然而 DM 也可以在怪物的威胁以某  
种形式消除时，同样给予相应的 XP 奖励。  
除非获得某些额外的说明，否则被法术或者魔法能力召唤出  
来的怪物同样拥有其资料卡中所列明的 XP。  
如何使用 XP 预算来创建遭遇，以及如何调整遭遇难度的相  
关内容在《城主指南》中已有说明。
