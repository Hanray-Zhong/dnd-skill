# 快手 Fast Hands

第 3 级起，你可以使用从“灵巧动作”特性中得到的附赠  
动作来进行一次敏捷（巧手）检定，或是以该附赠动作使用盗  
贼工具来解除陷阱、撬锁，或执行“使用物件”动作。
