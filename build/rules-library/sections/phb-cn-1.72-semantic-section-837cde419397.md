# 狂野魔法 Wild Magic

你天生的魔力来自于与创生之秩序相生相对的混沌之狂野  
力量。你也许曾经暴露于某种形式的原生魔力中；也许你穿越  
了一扇传送门到达了混沌海，元素位面，或者神秘的遥远国度。  
也许你受一名强大的精类生物祝福，或被一个恶魔选中；又或  
许你的魔力仅仅是天生如此，没有任何明确的原因。无论事情  
如何发生，这种混乱的魔力已经在你体内翻涌，随时等待着释  
放之时。
