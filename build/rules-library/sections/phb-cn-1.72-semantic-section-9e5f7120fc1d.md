# 获得激励 Gaining Inspiration

你的 DM 可以用各种理由给予你激励。典型的范例如：你  
在扮演时凸显了角色的个性特点；由于缺点或牵绊而使角色不  
得不屈服；甚至是生动的诠释你所扮演的角色时， DM 都可以  
酌情给予你奖励。具体情况皆由你的 DM 对其作出解释。  
面对某件事情时，你只会是有或者没有激励。“激励”无法  
积累起来留待后用。
