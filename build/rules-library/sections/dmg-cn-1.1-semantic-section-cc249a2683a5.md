# NPC 资料板 NPC Stat Blocks

《怪物手册》的附录 B 包含了一些常见的 NPC 范型（比  
如强盗 bandits 和警卫 guards）及其相应的自定小技巧。这些  
技巧包括增加《玩家手册》中所述的种族特质，为 NPC 装备  
魔法物品，以及替换其护甲、武器和魔法。  
如果你想要用 NPC 的资料板来匹配一个特定的怪物种族，  
则可以应用表格“ NPC 特性”中所述的属性调整值和相应的  
特性条目。如果该 NPC 的 AC、生命值、攻击加值或伤害发生  
改变，则重新计算其挑战等级。
