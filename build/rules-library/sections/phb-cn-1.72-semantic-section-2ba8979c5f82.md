# 探索机缘 Exploring Opportunities

半身人通常是为了守卫乡土、援助友人，或是为了见识充  
满惊喜的广阔世界而走上冒险之路。在他们眼中，冒险不是一  
份事业，而只是一些巧遇甚至是一种需求。
