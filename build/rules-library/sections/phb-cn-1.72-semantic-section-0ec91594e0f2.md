# 动作如潮 Action Surge

第 2 级起，你可以在短时间内突破极限，以使你在自己回  
合内执行一个额外的动作。  
该特性在使用后必须完成一次短休或长休才能再使用。第  
17 级起，你可在休息前使用两次该特性，但每一回合只能使用  
一次。
