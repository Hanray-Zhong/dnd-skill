# 巨武器大师 Great Weapon Master

你习得将武器重量作为优势的技巧，使你的攻击力大增。  
你获得下列增益：  
• 你在自己回合内用近战武器造成重击，或将一个生物生命值  
降至 0 时，可以用附赠动作发动一次近战武器攻击。  
• 你在使用具有熟练项的重型武器发动近战攻击前，可以选择  
让本次攻击检定承受 -5 罚值。若本次攻击命中，则其伤害掷  
骰获得 +10 加值。
