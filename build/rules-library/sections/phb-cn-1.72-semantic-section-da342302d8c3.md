# 斗殴高手 Tavern Brawler

你习惯了粗暴而混乱的肉体斗殴，而随手拿个东西都能成  
为你的武器。你获得下列增益：  
• 你的力量或体质加 1，上限为 20。  
• 你获得临时武器的熟练项。  
• 你徒手打击的伤害骰变为 1d4。  
• 你在自己的回合内用徒手打击或临时武器命中敌人时，可以  
用附赠动作尝试对该敌人进行一次擒抱。
