# 异界宗主 Otherworldly Patrons

邪术师的宗主是存在于其他位面的强大存在。他们不是神  
祇，却拥有与神祇相似的力量。不同的宗主可以给予旗下邪术  
师不同的力量与祈唤，并等待获得忠诚作为回报。
