# 进行追逐 Running the Chase

追逐事件参与者每个回合都会强烈希望执行疾走 Dash  
动作。猎手停下脚步施展法术或进行攻击时，必须冒跟丢猎物  
的风险。而猎物这么做时也可能会因此被抓。
