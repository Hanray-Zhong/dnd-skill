# 传奇动作 Legendary Action

传奇生物可以在其回合外执行特定次数的特殊动作，称为传  
奇动作。传奇动作只可以选择一个动作项，并且必须在另一生物  
回合结束时执行。传奇生物在其回合开始时恢复所消耗的传奇动  
作使用权。它可以放弃使用这些动作，且不能在陷入失能状态，  
或其他无法执行动作的时候使用这些动作。受突袭的生物直至其  
自己的第一个回合结束后，才能执行它的传奇动作。
