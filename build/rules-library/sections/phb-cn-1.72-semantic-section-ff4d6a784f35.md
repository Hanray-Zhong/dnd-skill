# 术法起源 Sorcerous Origin

选择一个术法起源作为你天赋魔力的源泉。你可在龙族血  
脉 Draconic Bloodline 或狂野魔法 Wild Magic 中选择其一。  
随后，你将在第 1、第 6、第 14、第 18 级获得相应起源的  
职业特性。
