# 灵活移动 Mobile

你十分灵敏而快速。你获得下列增益：  
• 你的移动速度增加 10 尺。  
• 你执行疾走动作的相应回合内，在困难地形的移动不再消耗  
额外的移动力。  
• 你对一个生物发动近战攻击后，无论命中与否，本回合剩下  
时间里你都不会引发该生物的借机攻击。
