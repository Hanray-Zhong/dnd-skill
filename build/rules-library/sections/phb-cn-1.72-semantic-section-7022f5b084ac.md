# 暗杀 Assassinate

第 3 级起，你一旦获得先机就会变得更加致命。你对战斗  
开始后还没开始过自己回合的生物发动攻击时，所进行的攻击  
检定具有优势。此外，你攻击命中被突袭的生物时，必定则造  
成重击。
