# 柱状 Cylinder

柱状效应范围的源点是其中一个截面圆的中心，相应法术  
的描述中会说明其圆的半径。而源点的截面圆必须位于地上，  
或位于法术效应范围的顶部。柱状的能量由源点直线展开到圆  
的周界，形成圆柱的底盘。然后，法术的效应从该截面圆由地  
面往上射或者从顶上往下射，直到达到柱状的高度。  
柱状区域效应的源点包含在效应之内。
