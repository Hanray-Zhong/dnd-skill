# 阵营 Alignment

大部分种族对某一阵营会有较强的倾向，这会在这一条目  
中说明。这并不会约束你构建角色时的自由，但仔细思考，如  
“为何你的矮人角色属于混乱阵营，而与守序的矮人社会背道  
而驰”等问题有助于你更好地构建角色。
