# 翻滚 Tumble

生物可以尝试翻滚穿过一名敌对生物所占空间位置，左  
闪右避的到达另一边。作为一个动作项或一个附赠动作项，翻  
滚者必须进行一次敏捷（体操）检定，以对抗敌对生物的敏捷  
（体操）检定。翻滚者赢得检定后，不能在同一回合里再移动  
穿越该敌对生物所在空间。
