# 基于地点的冒险 Location-Based Adventures

数不清的战役都奠基于破碎的地下城和偏远的荒野中。  
而许多最伟大的 D&D 冒险也都是基于地点的冒险。  
创建基于地点的冒险可以被分解为成若干步骤。这里为  
每个步骤提供了一些相应的表格，让你可以从中选用一些基  
本要素。此外你也可以依照表格掷骰随机选定要素，也可以把  
各步骤的次序重新编排。
