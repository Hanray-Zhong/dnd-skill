# 护甲等级 Armor Class

穿戴护甲或装备盾牌的怪物拥有的护甲等级（AC）等于其护  
甲、盾牌以及敏捷属性效果的总和。否则，怪物的 AC 将基于其  
所具有的敏捷调整值与天生护甲总和。如果该怪物具有天生护甲，  
同时穿戴护甲或装备盾牌，其具体 AC 值将纪录在基础值后的括  
号中。
