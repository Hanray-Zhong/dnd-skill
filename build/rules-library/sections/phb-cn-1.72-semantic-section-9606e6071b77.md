# 拨挡飞弹 Deflect Missiles

第 3 级起，你可以用你的反应拨挡或抓取一个击中你的远  
程武器攻击。使用本特性后，该次攻击的伤害将被削弱，其减  
数值等于 1d10 ＋你的敏捷调整值＋你的武僧职业等级。  
当被拨挡攻击的伤害减少至 0，且实施伤害的飞弹可以被  
你单手抓住时，你可以用此时空闲的手去抓取该飞弹。此时你  
可以消耗 1 点气以该“飞弹”进行一次远程攻击，而该攻击将  
视为本次反应的一部分。无论你是否具有被拨挡武器的熟练项，  
本次攻击中你都视为进行具有熟练项的攻击，所使用的飞弹也  
视为武僧武器，其射程为 20/60 尺。
