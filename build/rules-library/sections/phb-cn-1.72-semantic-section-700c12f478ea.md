# 材料 Material （M）

某些法术需要特定的物件才能施展，成分条目里会用括号  
具体注明。角色们可以使用材料包 component pouch 或法器  
spellcasting focus （详见第 5 章）取代法术所指定的材料。但  
如果一项法术的材料成分有指定的价格，则其每次施展时就必  
须备有这种特殊材料才行。  
如果法术的详述说某材料会作为该法术的耗材，则施法者  
每次施展该法术时都必须提供该材料。  
施法者必须有一只空手持握材料包，或者持握一个法器，  
不过持握材料的手可以是用来完成施法姿势的同一只手。
