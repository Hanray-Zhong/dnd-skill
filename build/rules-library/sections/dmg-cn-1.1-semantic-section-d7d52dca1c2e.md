# 简介

担当地下城主是一件美妙的事！你不仅能以此讲述那些  
充满英雄与恶棍、怪物与魔法的故事，还可以用这些故事创造  
一个世界。你可能已经主持过 D&D 游戏，或是刚刚对此提起  
兴趣，不论如何，本书正是为你而作。  
本《城主指南》的内容会先假设你已了解 D&D 这个桌上  
角色扮演游戏的基本规则。如果你从未接触过这个游戏，那么  
《龙与地下城新手包》对新手的玩家和 DM 们都是个很好的  
起点。  
本书还有另两本重要辅助资料：《玩家手册》中包含了你  
的玩家们用来创作角色，以及你用以进行游戏的规则，而《怪  
物图鉴》中则收集了生活在 D&D 世界中的各种怪物，随时可  
以用于你的战役。
