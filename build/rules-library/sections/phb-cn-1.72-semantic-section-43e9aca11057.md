# 德鲁伊结社 Druid Circle

德鲁伊组织的存在大多不为外人所知，然而他们确实分散  
在大陆各处，并且无视国界束缚的活动着。德鲁伊的社区会将  
任何德鲁伊视为其名义成员，尽管其中会有一些孤僻的个体从  
不与其他高阶成员接触，或是从不出席任何集会。德鲁伊们相  
互间情同手足，却也会如野性生物一样互相竞争，甚至互相残  
杀。  
某些德鲁伊还会因对自然、平衡以及行事方式等方面有着  
相同的观点而结成一些地域性组织。
