# 索引卡 Index Cards

这种方法要为每个角色准备一张索引卡，同时也为每组  
怪物准备相应的索引卡。玩家们轮流告诉你他们先攻的数值，  
你再把他们的相应数值写在各自的索引卡上。你自己也要为  
每组怪物的先攻做同样的工作。然后再牌面向上以从高到低  
的顺序堆栈卡牌。你点名堆栈顶部卡牌的角色名开始行动，并  
提示下一位准备，让相应的玩家开始思考。每个角色或怪物组  
行动过后，将顶部的卡牌移到堆栈的底部。  
使用战斗卡牌时，玩家们一开始并不知道游戏的顺序，在  
怪物开始行动前也不知道它们具体什么时候开始行动。
