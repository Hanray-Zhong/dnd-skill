# 法师之手诈术 Mage Hand Legerdemain

第 3 级起，你施展法师之手 mage hand 时可以制作一个隐  
形的幽灵手，且你可以用它来做下列特殊任务：  
• 你可以传递一个幽灵手持握的物件到其他生物携带或着装的  
容器中。  
• 你可以取回一个其他生物携带或着装容器内的物件。  
• 你可以用盗贼工具在其施法范围内撬锁和解除陷阱。
