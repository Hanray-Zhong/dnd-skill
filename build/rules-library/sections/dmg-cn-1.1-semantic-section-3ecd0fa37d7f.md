# 生意 Businesses

一名经营有生意的冒险者可以挣到足够的钱来支付自己  
的维护费用。但该生意的所有者必须平衡冒险与业务之间的  
时间，并且必须周期性地确保所有的事情都能顺利进行。详情  
见本章“休整期活动”一节关于经营生意的信息。
