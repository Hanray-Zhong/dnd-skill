# 山地矮人 Mountain Dwarf

作为一名坚强而健壮的山地矮人，你习惯于崎岖山地的艰  
苦生活。你肤色较浅，而身材在矮人中算是高个子。费伦大陆  
北部的盾矮人 shield dwarf，以及龙枪设定中掌权的海勒 Hylar  
氏族和贵族阶级的达瓦 Daewar 氏族都属于山地矮人。  
属性值加成 Ability Score Increase。 你的力量值加 2。  
矮人护甲训练 Dwarven Armor Training。你拥有轻甲和中  
甲的熟练项。
