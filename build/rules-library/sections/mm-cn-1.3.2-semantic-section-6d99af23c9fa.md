# 动作 Actions

怪物执行动作时，可以从其资料卡的动作栏中进行选择，也  
可以选择执行所有生物通用的动作，如疾走 Dash 或者躲藏 Hide。  
关于生物通用动作的更多信息，可参照《玩家手册》的相关内容。
