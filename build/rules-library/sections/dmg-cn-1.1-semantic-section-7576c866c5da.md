# 8. 规划遭遇 Plan Encounters

创建好大体的冒险故事后，你就可以准备规划那些与冒  
险事件相关的遭遇。在基于事件的冒险中，遭遇即是反派的计  
划与角色们前路的相交。你不可能总是准确地预测到什么时  
候会发生什么事，但大可以创建一个可能发生的遭遇清单。其  
中还可以整体描述一下反派的势力，其副官和手下的细节，以  
及与冒险关键地点相关的冒险。  
请参阅后文的“创建冒险”以获取自创遭遇的相关指引。
