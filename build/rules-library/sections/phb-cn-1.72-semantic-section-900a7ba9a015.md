# 法术成分 Components

法术的成分是施展该法术时必须满足的物质条件。每项法  
术的描述中都会说明其施展时是否需要言语 verbal （V）、姿势  
somatic （S）、材料 material （M）等成分。你只有满足一项法  
术所有的成分需求后才能施展相应的法术。
