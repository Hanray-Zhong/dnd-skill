# 协助 Help

你可以协助其他生物达成其行动。执行协助动作时，受你  
协助的生物进行相应行动时作出的下一次属性检定具有优势，  
所作检定必须在你下一回合开始前进行。  
此外，你也可以协助另一名友方生物攻击位处你身边 5 尺  
范围内的一个生物。你用假动作或其他手段干扰目标使受协助  
者更易攻击。如果受协助者在你下一回合前攻击该目标，则其  
首次攻击检定具有优势。
