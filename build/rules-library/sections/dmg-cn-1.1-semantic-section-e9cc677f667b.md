# 属性 Abilities

你不需要为 NPC 骰属性值，但要记录其比常见情况更低  
或更高的属性（比如力气很大，或蠢得出奇），并以此作为赋  
予 NPC 的素质。  
**角色属性 NPC Abilities**

| d6 | 高属性 |
| --- | --- |
| 1 | 力量——有力，肌肉发达，健壮如牛 |
| 2 | 敏捷——轻盈，灵活，优雅 |
| 3 | 体质——结实，精神抖擞，健康 |
| 4 | 智力——学习勤勉，博学，好思 |
| 5 | 感知——观察敏锐，思维敏感，洞察力强 |
| 6 | 魅力——有说服力，据理力争，天生的领袖 |
| d6 | 低属性 |
| 1 | 力量——虚弱无力，骨瘦如柴 |
| 2 | 敏捷——生硬无技巧，支吾笨拙 |
| 3 | 体质——病态，苍白 |
| 4 | 智力——缺心眼，慢半拍 |
| 5 | 感知——不警觉，心不在焉 |
| 6 | 魅力——枯燥，乏味 |
