# 艺人 Entertainer

你在观众面前的表演生涯下成长。逐渐学会如何取悦他人，  
如何令他们着迷，甚至学会了如何激励他们。你的诗篇挑动听  
众的心弦，带动他们的喜怒哀乐。你的音乐振作他们的精神，  
或勾起他们的伤感。你的舞步令人着迷，你的幽默一针见血。  
无论你擅长何技，艺术即是你的生命。  
技能熟练项： 体操，表演  
工具熟练项： 易容工具，一种乐器  
装备： 一种乐器（由你选择），倾慕者的信物（情书、一缕头发  
或者饰品），一套表演服装，以及一个装有 15 gp 的腰包
