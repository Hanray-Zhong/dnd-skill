# 快速建卡Quick Build

> 第 3 章中的每个职业描述中都提供了快速创建一个该职业角
> 色的建议，包括如何分配你的最高属性值，适合该职业的合适背景，
> 以及起始法术。

在你的角色卡上记下你的等级。如果你从较高等级开始，  
则还要记下你的职业在 1 级之后的等级提升时所获的其他元素。  
一个 1 级角色拥有 0 XP。而通常一个高等级角色开始时拥有达  
到当前等级所需最小值的 XP （见本章之后的“高于 1 级”）。
