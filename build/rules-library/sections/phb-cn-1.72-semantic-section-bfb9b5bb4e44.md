# 狂怒 Frenzy

从你第 3 级选择此道途起，你可以在狂暴时进入狂怒。使  
用此特性时，你可以在本回合之后狂暴持续时间内的每个回合  
里，以一个附赠动作发动一次近战武器攻击。而当狂暴终止时，  
你将提升一级力竭。
