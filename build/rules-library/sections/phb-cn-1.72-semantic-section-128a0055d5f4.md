# 四象宗 Way of the Four Elements

你追随一个教导掌控元素的宗派。你运气凝神时可以掌握  
创造之力，随意的驱使元素甚至将其当做躯体的延伸。宗派的  
某些成员会精修单一的元素，而其它人则同时使役所有元素。  
本宗派的许多武僧会用纹身描绘自身气的力量形式，比如  
盘龙或是诸如凤、鱼、树、山、奔浪等等。
