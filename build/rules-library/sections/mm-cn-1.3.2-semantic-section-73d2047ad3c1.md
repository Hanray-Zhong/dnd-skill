# 巡守纳迦 Guardian Naga

巡守纳迦作为睿智善良的美丽守护者保护着带有魔法力量  
的圣地与物品，以免落入邪恶之手。它们在其隐秘的棱堡中研究  
法术，并策划出复杂的计谋来挫败敌人的邪恶盘算。  
巡守纳迦不寻求暴力，更倾向于警告入侵者而非发动攻击。  
它们只在敌人顽固不化时动手，并以自己的法术和毒性唾沫来发  
动攻击。
