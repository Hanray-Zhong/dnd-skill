# 使用情节点数 Using Plot Points

开始时每个玩家都有 1 点情节点数。一次聚会中，玩家  
可以花费一点来达成一个效应。效应的具体内容取决于你的  
团队与该选用规则的适应程度。以下给出了三个选项。  
一名玩家在一次聚会中可以花费不超过 1 点的情节点数。  
不过你也可以提高这个上限，特别是当你想让玩家更多地讲  
述故事时就该如此。当游戏里的每个玩家都花费 1 点后，你  
就可以再给每人分配 1 点情节点数。
