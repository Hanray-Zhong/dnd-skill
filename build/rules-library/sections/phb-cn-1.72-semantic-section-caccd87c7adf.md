# 特性：研究发现 Feature: Discovery

你寂寥的长期隐居令你发现了某些独特而强大的秘密。这  
项发现的具体内容与你的隐居的理由密切相关。你或许是找到  
了与宇宙真相，神祇本质，异界大能或是自然之力等相关的伟  
大真理。你也可能是发现了某处任何人都未曾发现的地点。你  
可能揭露了久被遗忘的真相，或是发掘出了久远史前的遗物。  
或者，你也可能是发现了那些一手导致你流放的家伙们相关的  
情报，而那也就是你重返凡世的契机。
