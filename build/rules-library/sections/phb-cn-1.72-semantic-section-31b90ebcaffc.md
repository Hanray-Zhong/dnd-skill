# 诡术领域 Trickery Domains

诡术之神们（如泰摩拉 Tymora、本莎芭 Beshaba、渥利达  
马拉 Olidammara、旅者 Traveler、加尔 · 闪金 Garl Glittergold、  
和洛基 Loki）均是恶作剧者，同时也是挑拨凡人或神明去颠覆  
现有秩序的煽动者。祂们是小偷、恶棍、赌徒、叛乱者和解放  
者的庇护人。其牧师则是世界的颠覆者，他们打击骄傲者的自  
尊，嘲弄暴君，窃盗富人，释放俘虏，并且蔑视毫无意义的传  
统。他们喜欢花言巧语、恶作剧、欺骗和盗窃要远远多于正面  
对抗。
