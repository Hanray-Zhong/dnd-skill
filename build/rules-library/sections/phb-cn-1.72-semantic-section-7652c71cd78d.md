# 隐匿 Stealth

以慢速步调旅行时，每个角色可以在移动的同时保持隐匿。  
如果队伍同时身处非开放的区域，则他们还可以进行突袭或避  
开所遭遇的其他生物。有关躲藏的规则详见第 7 章。
