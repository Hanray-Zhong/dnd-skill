# 术法点 Sorcery Points

开始时，你拥有 2 个术法点。此后你每提升一个术士等级，  
都会获得更多的术法点，详见“术士职业表”中“术法点”一  
栏。你的术法点永远不能超过表中所列对应你当前等级的数值。  
而已消耗的术法点则可以通过完成一次长休进行恢复。
