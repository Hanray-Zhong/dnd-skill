# 技能和精准 Skill and Precision

游荡者致力于掌握多种技能的使用方法，并以此完善其作  
战能力，因此他们在许多领域的专业知识都让其他角色难以企  
及。很多游荡者专注于潜行和骗术，而另一些则精于针对地城  
环境的有效技能，诸如攀爬、搜索、解除装置和开锁。  
战斗时的游荡者则是更偏爱狡猾而非蛮横。与其用密集攻  
击放倒敌人，他们更喜欢针对敌人的弱点部位进行精准打击。  
游荡者们用近乎超自然的本领规避危险，而其中少数还会学习  
运用诡术魔法作为其能力的补充。
