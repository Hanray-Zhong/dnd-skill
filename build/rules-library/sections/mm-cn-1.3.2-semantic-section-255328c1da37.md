# 水下 Underwater

并非所有冒险都发生在陆地。本书还提供了一些出没在海洋  
世界的生物，比如，邪恶的沙华鱼人，以及与之敌对的善良水生  
精灵。这些水生领域也是充满惊奇的冒险地带：  
• 一片沉船的墓地，徘徊着鲨鱼、水生食尸鬼和愤怒的幽魂  
• 一座风暴巨人的珊瑚城堡，四处透露着美丽与危险的气息  
• 一座海底的失落城市，笼罩在一个魔法气泡中，由一位美杜莎  
女王统治着  
• 一个克拉肯洞穴或青铜龙巢穴，里面放满了古老的宝藏  
• 一座沉没的塞克拉神庙 Sekolah，里面供奉着沙华鱼人的邪恶  
神祇
