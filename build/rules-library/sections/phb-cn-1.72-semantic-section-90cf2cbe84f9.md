# 宗派 Monastic Tradition

第 3 级时，你选择投入一个宗派精进你的技艺。你可以从  
散打宗、暗影宗、四象宗中选择其一。随后，你的将在第 3、第  
6、第 11、第 17 级时获得相应宗派的特性传承。
