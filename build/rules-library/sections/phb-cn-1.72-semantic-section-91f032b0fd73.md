# 特性：特权地位 Feature: Position of Privilege

由于你的贵族血统，人们总是会予你优待。高等社会愿意  
接纳你，人们认同你有权去任何你想去的地方。平民们会尽力  
满足你的要求，避免你产生任何不快，而那些同样出身高贵的  
人则会视你为同一个社会圈子的人。你还可以在必要时前去拜  
会任何当地的贵族。
