# 游荡者范型 Roguish Archetypes

游荡者们有着许多共同的特性，包括技能的精进、致命而  
精准的战斗手法，还有不断增强的反应能力。但游荡者们还会  
各自套用各种范型，并从不同的方向发挥这些天赋的作用。你  
选择的范型反映出你所专注的领域，其并不代表你的专业工作，  
只是体现你冒险时的惯用技巧。
