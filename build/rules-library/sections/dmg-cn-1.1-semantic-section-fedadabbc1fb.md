# 房间现状 Current Chamber State

如果一个地下城曾经历一段动荡的历史，那么你可以掷  
骰确定某个特定区域的现状。不过，如果该房间仍然用于实现  
其预定的用途，则表示其完好无损。  
**房间现状 Current Chamber State**

| d20 | 特征物 |
| --- | --- |
| 1~3 | 瓦砾，天花板部分倒塌 |
| 4~5 | 坑洞，地面部分倒塌 |
| 6~7 | 灰烬，主要是燃烧所致 |
| 8~9 | 用作一个营地 |
| 10~11 | 一池水；房间原本的内容物被水毁坏 |
| 12~16 | 家具受损但仍然存在 |
| 17~18 | 转为作其他用途（骰表格“通用地下城房间”） |
| 19 | 空无一物 |
| 20 | 维持原状且光洁如新 |
