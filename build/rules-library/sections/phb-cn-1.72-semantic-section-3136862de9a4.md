# 专精 Expertise

第 3 级起，你选择两个已有的技能熟练项。此后你进行所  
选技能的属性检定时，可以使用双倍的熟练加值。  
第 10 级后，你可以再选择另外两个已有的技能熟练项从  
该特性中获益。
