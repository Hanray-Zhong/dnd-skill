# 施法关键属性 Spellcasting Ability

魅力是你施展邪术师法术的关键属性。每当你的法术需要  
施法关键属性时均指向你的魅力值。而你邪术师法术的豁免 DC  
和攻击检定，则使用你的魅力调整值。  
法术豁免 DC ＝ 8 ＋你的熟练加值＋你的魅力调整值  
法术攻击调整值 ＝你的熟练加值＋你的魅力调整值
