# Book

本书编排为三个部分。第一部分帮你将战役设定成你心  
目中的样子。第二部分助你创作战役故事，并以此维系整个冒  
险的连贯性与吸引力，让玩家们能够一次次的参与到游戏聚  
会中。最后一部分则帮你裁定或调整游戏规则，以适应你自己  
的战役风格。
