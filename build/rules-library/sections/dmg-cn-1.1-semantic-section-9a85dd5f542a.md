# 按预算构建遭遇 Building Encounters on a Budget

构建遭遇的难度应该合理，该难即难。队伍的 XP 阈值相  
当于你花费来构建怪物的 XP 预算，并以此选择建立简单、中  
等、困难和致命的遭遇。但请牢记一点，即怪物组合所消耗的  
预算比其基本 XP 值所表示的要多（见第 4 步）。  
以第 2 步所述的队伍为例，你为其构建中等遭遇时只要  
确保调整后的怪物 XP 值至少为 550 XP （该队伍中等遭遇阈  
值），且不得超过 825 XP （该队伍困难遭遇阈值）即可。一个  
挑战等级 3 （诸如刺尾狮 manticore 或枭熊 owlbear）的单一  
怪物价值 700 XP，这就足以满足该预算。如果您想要一对怪  
物，则其中每个都将算作价值其基本 XP 值的 1.5 倍。一对恐  
狼 dire wolves （每只价值 200 XP）其调整后的 XP 值即为 600，  
于是它们也满足该队伍的总等遭遇条件。  
附录 B 中列出了几份将《怪物图鉴》中的怪物按挑战等  
级重新排列的清单，以方便大家应用该方法。
