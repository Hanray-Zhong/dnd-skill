# 强弩专家 Crossbow Expert

你凭借一系列的用弩修行，获得下列增益：  
• 你使用拥有熟练项的弩时，忽略其装填属性。  
• 你在敌对生物５尺范围内发动远程攻击检定时，不会因此而  
具有劣势。  
• 你执行攻击动作以单手武器攻击后，可以用附赠动作使用一  
把正持握的手弩发动攻击。
