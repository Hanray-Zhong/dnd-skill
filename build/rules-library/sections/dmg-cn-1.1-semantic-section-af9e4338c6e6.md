# 废墟 Ruins

破碎的塔楼，远古的神庙，以及被夷为平地的城市都是探  
险的绝佳场所。此外，你还可以注意到，一堵沿着道路引申的  
破碎古墙，一座山顶上的石制风车，或是一堆石砌的石头，都  
可以给为你的野外环境增添质感。
