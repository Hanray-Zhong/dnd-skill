# 导航 Navigation

航海载具航行时会尽量接近海岸，这样可以利用可见地  
标使导航更容易进行。只要船上能看到陆地，航路就不会迷失。  
如果看不到陆地，船队的领航员就必须依靠航行轨迹来推断  
船队的位置（通过跟进船方向和航行距离）。条件允许时，也  
可以利用天上的星星和太阳进行定位。  
参照本章早前所述的表格“野外导航”来确定船舶是否偏  
离航道。
