# 选用规则：心灵失调 Psychic Dissonance

每个外层位面都散发着一种心灵失调感，并影响每个与  
其阵营不相容的访客（善良生物在下层位面，或邪恶生物在上  
层位面时），前提是他们必须在该位面中待得时间够长。你可  
以选用该规则来反映这种失调感。在一个阵营不相容的位面  
完成一次长休后，该旅者必须进行一次 DC10 的体质豁免。豁  
免失败者将提升一个等级的力竭状态。守序与混乱阵营间的  
不相容不会产生这种效应，因而机械境 Mechanus 和混沌海  
Limbo 也不会出现这种特征。
