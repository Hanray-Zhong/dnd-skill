# 有用知识 Useful Knowledge

以一句话描述 NPC 拥有某些可能对玩家角色们有用的知  
识。 NPC 可能知晓一些普通事如城中哪里最好的旅店，或者  
掌握一些重要事情如谋杀案的线索。
