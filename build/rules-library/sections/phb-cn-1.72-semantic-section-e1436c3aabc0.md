# 变体罪犯：密探 Variant Criminal: Spy

虽然你的能力水平与那些盗窃犯或走私犯区别不大，但你  
却层以一种不同寻常的方式接受教育与训练：即作为一名从事  
谍报活动的探子。你可能曾是一名官方认可的皇家密探，也可  
能是价高者得的情报贩卖者。
