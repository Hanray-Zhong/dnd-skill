# 开支 Expenses

当未前去深入地底，探寻宝藏，或勇战黑暗势力时，冒险  
者们也需要面对现实生活。即便时在这个神奇的世界中，人们  
也有衣食住的基本需求。而这些生活的花费也存在穷奢之分。
