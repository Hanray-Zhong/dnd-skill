# 目标 Targets

大部分法术都会需要你指定一名或多名受法术魔法影响的  
目标。法术的相关描述会详述其目标为生物，物件或是作为区  
域效应原点的空间内某一点（详见下文）。  
除非法术有可以观察到的效应，否则作为目标的生物不会  
知道自己已成为法术的目标。噼啪作响的闪电打中谁是大家都  
看得见的，但读心等较不显眼的效果一般都不会被发现，除非  
法术另有说明。
