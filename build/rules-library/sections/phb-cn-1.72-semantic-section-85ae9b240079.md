# 言语 Verbal （V）

大多数法术都需要咏唱咒文。虽然这些咒文并不给法术供  
应魔力，但其特定音高共呜的声音组合却可以牵动魔网的弦线  
来完成施法。因此，如果你被塞住嘴巴或者身处静默的空间（如  
沉默术 silence 的效应范围），则你将不能施展带言语成分的法  
术。
