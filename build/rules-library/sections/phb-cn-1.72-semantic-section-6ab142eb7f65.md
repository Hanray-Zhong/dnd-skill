# 猎人 Hunter

选择猎人范型，意味着你接受文明社会与惊粟荒野间的交  
界作为你的战斗岗位。走上猎人之路后，你将学习专业的战斗  
技巧，并面临的各种威胁：从狂暴的食人魔和成群的兽人，到  
高耸的巨人和可怕的龙都是你前进的障碍。
