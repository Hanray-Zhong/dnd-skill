# 世间诸神

《玩家手册》中的附录 B 列明了一些神系（不被统一教  
条或哲理联合在一起的松散神祇集合）供你应用于自己的游  
戏中，其中包括了一些现有完善的 D&D 世界其内的神祇，以  
及历史上的奇幻神系。你可以从中选择一整个神系应用于你  
的战役，或是在其中随意挑选一些神祇或其相关概念。本节的  
“神系范例”段落可以作为其中一种参考。  
你的世界存在百万众神，或是所有教堂只供奉单一神祇  
都不会与游戏的相关规则产生冲突。所有的规则条款中，牧师  
只是选择领域而非特定神祇，因此你的世界可以随意的将任  
何领域赋予任何你所指定的神祇。
