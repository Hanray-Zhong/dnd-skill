# 超凡技艺 Peerless Skill

第 14 级起，你进行属性检定时，可以花费一次诗人激励  
次数并掷一次激励骰，然后将结果加到你的属性检定上。你可  
以在掷完属性检定后， DM 宣布结果前决定是否使用此特性。
