# 半精灵姓名 Half-Elf Names

半精灵按照精灵或人类的习俗取名。讽刺的是，在人类社  
会长大的半精灵常取精灵名字，而在精灵社会中的半精灵则常  
取人类名字，就仿佛在强调他们并不真正属于任何一方。
