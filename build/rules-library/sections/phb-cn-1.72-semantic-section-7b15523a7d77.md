# 刺客 Assassin

你专注于残忍冷酷的死亡艺术。许多不同的游荡者都会追  
随此范型：诸如雇佣杀手，间谍，赏金猎人，甚至还有那些专  
为神祇歼灭敌人的特殊祭司。他们会结合利用隐匿、下毒、易  
容等手段有效的铲除敌人。
