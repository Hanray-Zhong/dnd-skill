# 施法关键属性 Spellcasting Ability

你的法术力量源于你对自然的信仰与同调，因此感知是你  
施展德鲁伊法术的关键属性。每当你的德鲁伊法术需要施法关  
键属性时均指向你的感知值。而你德鲁伊法术的豁免 DC 和攻  
击检定，则使用你的感知调整值。  
法术豁免 DC ＝ 8 ＋你的熟练加值＋你的感知调整值  
法术攻击调整值 ＝你的熟练加值＋你的感知调整值
