# 无关 XP 的等级提升 Level Advancement without XP

你可以完全舍弃经验值来控制角色成长的速度。你可以  
根据计划中需要进行多少次游戏聚会，或者什么时候达成战  
役中特定的故事目标等安排来提升角色。不管哪一种情况，你  
都必须在玩家角色升级时作提醒。  
如果你的战役不包含太多的战斗，或者包含了太多战斗  
而使跟进 XP 变得很累人时，使用这种升级方案会特别有用。
