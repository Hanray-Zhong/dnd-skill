# 特性：军衔 Feature: Military Rank

你作为士兵时曾获得过军衔。那些忠于你之前所在组织的  
士兵仍会承认你的权威与影响，而其中军衔比你低的人甚至依  
然会遵从你的命令。凭借军衔的影响，你可以向其他士兵临时  
征用简单的装备或马匹。并且还可以凭此随意通过那些承认你  
军衔的友方军队大营和堡垒。
