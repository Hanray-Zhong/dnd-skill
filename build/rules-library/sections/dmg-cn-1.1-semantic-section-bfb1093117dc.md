# 记忆丧失 Memory Loss

离开妖精荒野的生物必须进行一次 DC10 的感知豁免。精  
类生物，以及任何拥有“精类血统 Fey Ancestry ”特质的生物  
进行该豁免时直接判为成功。豁免失败的生物将失去所有在  
妖精荒野中所度过时光的相关记忆。豁免成功时，该生物保留  
其记忆但会有点模糊。任何可以解除诅咒的法术都可以恢复  
该生物所失去的记忆。
