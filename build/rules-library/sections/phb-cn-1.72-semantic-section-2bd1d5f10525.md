# 特性：漂泊者 Feature: Wanderer

你对记忆地图和地形时能力惊人，且你总能回想起地形、  
定居点或者其他环境特征的大致布局。此外，你每天可以为自  
己以及至多五名队友获取食物和饮水，前提是你们身处的土地  
可以提供浆果、小野兽、水源等资源。
