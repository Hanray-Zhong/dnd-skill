# 专注 Concentration

某些法术需要你保持专注才能持续激活其魔力。如果你失  
去专注，法术也随即终结。  
需要专注的法术会在其持续时间条目中说明，同时还会指  
明专注时间的上限。你可以随时停止专注而无须执行动作。
