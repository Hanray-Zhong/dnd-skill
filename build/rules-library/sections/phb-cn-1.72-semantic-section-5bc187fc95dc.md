# 轻甲 Light Armor

用柔软轻薄材料制成的轻甲，因其能在不牺牲机动性的同  
时提供一定的防护而为注重灵巧的冒险者所喜爱。着装轻甲时，  
你将敏捷调整值加到护甲种类的基本数值上，即为你的护甲等  
级。  
布甲 Padded。 布甲由数层布料与棉料的衬里构成。  
皮甲 Leather。该护甲的护胸和护肩由通过油煮硬化的皮  
子制成。护甲的其余部分则由更软更灵活的材料制作。  
镶钉皮甲 Studded Leather。 该护甲由坚固而柔韧的皮革  
制成，其表面由紧密的铆钉和尖刺进行加固。
