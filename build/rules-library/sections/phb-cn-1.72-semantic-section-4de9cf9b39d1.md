# 暗影技艺 Shadow Arts

第 3 级你选择本宗派起，你可复制某些特定法术的效应。  
你可用一个动作消耗 2 点气以施放黑暗术 darkness，黑暗视觉  
darkvision，行动无踪 pass with trace 或沉默术 silence，且无需  
材料成分。此外，若你仍未习得戏法次级幻影 minor illusion，  
则你将获得该戏法。
