# 坚韧狂暴 Relentless Rage

第 11 级起，狂暴的力量让你即使身受重伤也能持续战斗。  
如果你的生命值降至 0 但并未立即死亡，则你可以进行一次  
DC10 的体质豁免。豁免成功则改为你的生命值降至 1。  
第一次使用此特性后，每当你再次使用此特性时其体质豁  
免 DC 提高 5。在你完成一次短休或长休后其 DC 重置为 10。
