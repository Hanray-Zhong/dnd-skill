# 附录 B：非玩家角色 Nonplayer

该附录所包含的资料，属于 D&D 战役中可能与冒险者遭遇  
的各种类人生物类非玩家角色（NPC）。其中的人物从卑微至平民  
commoner，强大如大法师 archmage 等角色。这些资料板可以用  
来代表任何人类或非人类的 NPC。
