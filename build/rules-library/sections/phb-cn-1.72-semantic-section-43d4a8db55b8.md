# 快速建卡 Quick Build

你可以按以下建议快速创建一名吟游诗人。首先，将最高  
属性分配给魅力，次高属性分配给敏捷。然后选择艺人背景。  
最后选择戏法舞光术 dancing light 和恶言相加 vicious mockery，  
选择 1 环法术魅惑人类 charm person、侦测魔法 detect magic、  
治愈真言 healing word 和雷鸣波 thunderwave。
