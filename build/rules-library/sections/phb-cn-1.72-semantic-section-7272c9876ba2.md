# Feature: City Secrets

你熟知城市中的秘密小路和胡同，能够在其他人容易迷失  
的混乱街区中寻路。如果你们并非身处战斗状态，则你还可以  
在市区内引导同伴以两倍的平时速度在两个地点间穿行。
