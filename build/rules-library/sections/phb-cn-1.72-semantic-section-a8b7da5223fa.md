# 灵活施法 Flexible Casting

你可以使用术法点来获得额外的法术位，或是消耗法术位  
来换取额外的术法点。随着术士等级的提升，你还可以学会其  
他术法点的使用方法。  
生成法术位 Creating Spell Slots。 你可以在自己回合内以  
附赠动作将未使用的术法点转换为法术位。表格“生成法术位”  
中列出了生成各法术位所需的术法点数。另外，你无法生成高  
于 5 环的法术位。以此方式生成的法术位将在完成一次长休后  
消散。
