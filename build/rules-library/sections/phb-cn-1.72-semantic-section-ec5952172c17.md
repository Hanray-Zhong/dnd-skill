# 语言学家 Linguist

你学习了不少语言和密码，获得下列增益：  
• 你的智力加 1，上限为 20。  
• 你习得三门自选语言。  
• 你可以自创密码。而未经你传授解密方法的人只有两种方法  
可以破译你的密码：其一是进行智力检定（DC 等于你的智力  
值＋你的熟练加值），或是以魔法破译。
