# 预兆 Portent

从第 2 级你选择该学派起，预知未来的片段会时常在你意  
识中闪过。你在每次完成长休时投两次 d20 并记下两组骰值。  
此后，你可以用这两组预知骰骰值中的任意一个，替代任何一  
次由你，或者由你能看见的某个生物所进行的攻击检定，豁免  
检定或属性检定。你必须在相关检定开始前决定是否使用预知  
骰，且你每回合只能使用一次预知骰。  
每个预知骰只能使用一次。你完成一次长休后，将失去所  
有未使用的预知骰。
