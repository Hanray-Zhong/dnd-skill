# 大德鲁伊 Archdruid

第 20 级时，你可以无限次的使用荒野变形。  
另外，你还可以将德鲁伊法术中的姿势和语言成分，以及  
非无价值且不被法术消耗的材料成分忽略。你在原形态和荒野  
形态下都可以从此特性获益。
