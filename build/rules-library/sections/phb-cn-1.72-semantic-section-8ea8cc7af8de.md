# 致命一击 Death Strike

第 17 级起，你熟练掌握瞬杀的技巧。你攻击命中一个被  
突袭的生物时，该生物必须进行一次体质豁免（DC8 ＋你的敏  
捷调整值＋你的熟练加值）。豁免失败时，你将对其造成双倍伤  
害。
