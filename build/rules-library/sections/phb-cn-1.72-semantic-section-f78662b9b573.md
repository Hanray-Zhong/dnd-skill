# 盗贼 Thief

你专注于训练盗窃的技能。窃贼，强盗，扒手和其他的犯  
罪类型常常会追随此范型，还有那些自称寻宝者，探险家，探  
索者和调查员的游荡者也是如此。除了提升灵巧和隐匿的技艺  
外，你还将学会如何探索古代废墟，解读罕见的语言和使用魔  
法物品的技巧。
