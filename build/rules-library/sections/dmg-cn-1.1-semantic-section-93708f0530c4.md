# 主题变换 Variations on a Theme

将各种事物杂糅在一起，有时可以让玩家们体验到多样  
化的冒险。就算是主题紧凑的战役也会或多或少的出现偏颇。  
如果你的战役大量涉及密谋、神秘事物和角色扮演，那你的玩  
家也许会享受偶尔造访地下城的主意——尤其是当故事出现  
转机并揭晓某个战役中的大阴谋时。如果冒险者中多数人倾  
向地城远征，则可以将那些紧凑的城中神秘事物作一些转换，  
然后把队伍引导到某个废弃建筑或塔楼里进行地城探险。如  
果你主持一场每周开展的恐怖冒险，则可以尝试使用一个普  
通的反派，或者甚至是有点傻的反派。幽默的解说在几乎所有  
D&D 战役里都是一种优秀的转折，有时甚至玩家自己也会创  
作这种转机。
