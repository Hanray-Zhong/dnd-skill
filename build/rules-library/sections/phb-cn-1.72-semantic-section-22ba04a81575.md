# 反应 Reaction

某些法术可以作为反应进行施展。这类法术通常只需要几  
分之一秒完成，因此可以用作对事件的应对。如果一项法术可  
以作为反应进行施放，则法术的详细描述会明确说明你在什么  
情况下能以它作反应。
