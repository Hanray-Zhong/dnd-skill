# 熟练加值 Proficiency Bonus

你的熟练加值永远以你角色的总等级为基础进行计算，而  
非你所具有的某一项职业等级。例如，一名战士 3 ／游荡者 2  
会有 5 级角色的熟练加值，也就是 +3。
