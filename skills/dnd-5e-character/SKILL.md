# 角色能力

维护角色构成、派生数据与当前状态的边界，校验字段变更权限并生成状态变更请求。当前可为已确认玩家名册中的角色调用 `dnd-5e recalculate`，将显式带单位输入交给固定公式目录，并把完整审计轨迹提交给状态边界。尚未建立可信角色构成、桌规或模组效果记录时不得提交非空修正集，也不得把调用方自报的来源或优先级视为授权。不得直接编辑战役状态库，玩家记录或临时公式输入也不能自动覆盖权威角色构成。
