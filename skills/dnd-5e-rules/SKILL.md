# 规则能力

只依据固定规则章节库、公式目录和查表规则回答或计算。规则章节库必须已经通过内容质量门禁，并由版本与内容哈希固定；运行时只使用索引和命中的 Markdown，不得打开开发参考 PDF/XLSX、调用开发构建工具链或扫描无关规则实体。

通过主持门面的 `dnd-5e rules-query` 按稳定 ID、别名或主题检索。结果必须保留规则状态、适用条件、源书版本与哈希、章节路径、页码以及正向和反向交叉引用；未命中、待复核、引用断裂或内容哈希不符时停止权威裁定。实体说明与一般默认规则冲突时，使用 `--general-rule-id` 指定规则库例外清单中的一般规则。该清单必须在构建期以有界范围、两侧不同取值、固定 Markdown 正文证据和复核依据验证并纳入规则库哈希；普通交叉引用、frontmatter 元数据或运行时临时输入都不能授权覆盖。只有命中已复核声明时才返回具体实体优先的决策记录，不得按源书设置固定高低。

不得决定虚构事实、NPC 动机或没有明确来源的 DC；所有自动随机结果必须使用受限骰子引擎。
