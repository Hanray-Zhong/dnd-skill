# 战役状态

这是唯一持久状态边界。校验带前置修订、幂等键、来源、受众和预期差异的状态变更请求，并以 SQLite 事务原子保存实体快照、不可变事件、认知、受众、请求结果与修订。公式派生数据请求必须在事务前使用当前固定公式目录独立复算，只有结果与请求中的完整审计轨迹一致时才允许保存。相同请求重试必须返回原事务；不同请求复用同一幂等键或基于过期修订时必须拒绝。不得作规则裁定、冒险准备或叙事决定。
